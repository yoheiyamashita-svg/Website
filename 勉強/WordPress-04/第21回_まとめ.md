# プラグイン
## プラグインとは
- WordPressに機能を追加する拡張機能。よく使われる機能を、自分で開発しなくても取り入れられる

## 導入方法
1. 管理画面の「プラグイン」→「新規追加」
2. 検索欄でプラグイン名やキーワードを検索する
3. 「今すぐインストール」→「有効化」
4. 一覧で「無効化」と表示されていれば有効になっている

## 注意点
- レビューが極端に悪いものは使わない
- 長い間更新されていないものは、バージョンの違いでエラーが起きたり、セキュリティの弱点になったりする
- 使いすぎると、サイトが重くなったり、プラグイン同士がぶつかってエラーが起きたりする。適度に使う
- 無料プラグインは開発が止まることもある。定期的に脆弱性の報告を確認し、アップデートする
- 📎 [WordPressのおすすめプラグインを導入しよう](https://zero-plus.io/media/l_wordpress/recommend-plugins/)

# お問い合わせフォーム（Contact Form 7）
- 日本語対応のフォーム作成プラグイン。利用者が多く、エラー対応やカスタマイズの情報も見つけやすい

## 作り方
1. Contact Form 7をインストールして有効化する
2. 管理画面の「お問い合わせ」→「新規追加」でフォームを作る
3. `page-contact.php`の`form`タグの**中身**を切り取り、管理画面のフォーム欄に貼る
    - **`form`タグは書かない**（Contact Form 7が自動で作るので消す）
4. 入力欄やボタンを、Contact Form 7のタグに置き換える
    - 必須なら「必須入力の項目」にチェックを入れる（タグに`*`がつく）
    - もともとつけていたクラスは「クラス属性」に入れる
5. 保存すると出てくる**ショートコード**を、お問い合わせの固定ページに貼る
6. `page-contact.php`の切り取った場所に`<?php the_content(); ?>`を入れる（固定ページの本文＝フォームが表示される）

```html
<!-- 置き換え前（HTML） -->
<input type="text" class="contact_form_input" />

<!-- 置き換え後（Contact Form 7のタグ） -->
[text* your_name class:contact_form_input]
<!-- text＝種類、*＝必須、your_name＝名前、class:＝クラス属性 -->
```
- 📎 [Contact Form 7でお問い合わせ機能を実装しよう](https://zero-plus.io/media/l_wordpress/contact-form-7/)／[ブログサイトをWordPress化しよう お問い合わせ機能編](https://zero-plus.io/media/l_wordpress/html-to-wordpress-contact-form/)／[タグの使い方（Contact Form 7公式）](https://contactform7.com/ja/tag-syntax/)

## 表示が崩れたとき
管理画面のコードに空白などがあると、余計な`p`タグや`br`タグが自動で入ることがある。`functions.php`に次を書くと防げる。
```php
// Contact Form 7で自動挿入されるpタグ・brタグを削除する
add_filter('wpcf7_autop_or_not', 'wpcf7_autop_return_false');
function wpcf7_autop_return_false() {
  return false;
}
```

## メールの設定
- 「メール」タブで、届くメールの内容を設定する
- フォームでつけた**タグの名前**と、メールに書く`[〇〇]`が一致している必要がある
    - 使える名前は「メール」タブに表示されているので、その中から使う
    - `your-email`と`your_email`のように、ハイフンとアンダーバーを間違えやすい
- `_site`から始まる特殊なメールタグは、WordPressの設定を自動で取得する。基本的に書き換えなくてよい

| タグ | 取得するもの |
| --- | --- |
| `[_site_admin_email]` | 管理者メールアドレス |
| `[_site_title]` | サイトのタイトル |
| `[_site_url]` | サイトのURL |
| `[_site_description]` | サイトのキャッチフレーズ |

- 「メッセージ」タブで、エラー時や送信完了時のメッセージを、状況が伝わるように書き換えられる
- 📎 [特別なメールタグ（Contact Form 7公式）](https://contactform7.com/ja/special-mail-tags/)

## スパム対策（reCAPTCHA）
- お問い合わせフォームにはスパム対策が必須。Googleの**reCAPTCHA**がおすすめ（📎 [Contact Form 7の使い方とreCAPTCHAの設定](https://www.xserver.ne.jp/bizhp/wordpress-contact-form-7/)）
- reCAPTCHAは2025年末までにGoogle Cloudプロジェクトへの移行が必要（📎 [Contact Form 7からのお知らせ](https://contactform7.com/ja/2025/02/10/our-future-plans-for-captchas/)／[移行で何が変わる？費用は？](https://www.ailesys.co.jp/archives/15087)）

## Contact Form 7以外の方法
| 方法 | 特徴 |
| --- | --- |
| Google Form | セキュリティが高く簡単に作れる。URLを貼るだけだと見た目がGoogle Formのまま。埋め込めばCSSで調整できる |
| 外部サービス | セキュリティが高く、集計機能などがあるものも。無料版は受信数などに制限があることが多い |
| PHPで自作 | セキュリティが甘く情報流出の危険があるので、公開サイトでは避ける（勉強ならよい） |
| MW WP Form | 以前は人気だったが、開発側が新規採用を控えるよう公言しているので使わない |
| Snow Monkey Forms | 「入力・確認・完了」の画面を簡単に作れる。確認画面が必要なときに検討する |

# セキュリティ（SiteGuard WP Plugin）
サイトのセキュリティを強化する。特に不正ログイン対策。
- **ログインURLの変更**：標準の`/wp-login.php`を、ランダムな文字列を含むURLに変えて、ログイン画面を見つけにくくする
- **管理画面へのアクセス制限**：ログインしていないIPアドレスからの管理画面へのアクセスを防ぐ（「管理ページアクセス制限」をONにして保存）
- ログイン履歴（成功・失敗）も確認できる

# サーバーアップとバックアップ
- プラグイン**WPvivid Backup Plugin**を使うと、コードや管理画面の設定など、サイトのすべての情報を別のWordPressにコピー・復元できる
    - データのバックアップ、サーバーアップ、質問フォームで見てもらうときに使える
    - 📎 [WPvividの使い方（バックアップ＆移行）](https://tcd-theme.com/2024/10/wpvivid.html)

## 既存サイトの修正は本番で直接やらない
保守・修正の案件では、次の手順で作業する。
1. サイトのバックアップをとる（サーバー会社のバックアップ、BackWPup、WPvividなど）
2. WPvividで、本番サイトをLocal環境にコピーする
3. Local環境で修正して、動作を確認する
4. 修正したファイルをFileZillaでアップロードする、またはWPvividで本番に復元する
5. 本番サイトの表示を確認する

# 【卒業後】作業のテンプレート化
毎回同じプラグインを入れる、同じCSS・スクリプトの読み込みを書く、日本語化やnoindexの設定をする……という手間を省ける。
- Localなら**Blueprint**で雛形を作れる（📎 [LocalのBlueprintの使い方](https://junpei-sugiyama.com/local-blueprint/)）
- XAMPPやMAMPの場合は、バックアップファイルをテンプレートにする
    1. 毎回必要なプラグイン・ファイル（`functions.php`の定番コード、インクルードタグなど）・設定を入れた状態を作る
    2. WPvividなどで、管理画面の情報ごとエクスポートする
    3. 新しいWordPressに同じプラグインを入れて、インポートする
    4. 必要ならログインのユーザー名・パスワードを変える（そのまま引き継がれるので管理に注意）

# 今回の授業のポイント
1. プラグインの入れ方と、入れるときの注意点
2. Contact Form 7では`form`タグを書かない。フォームのタグ名とメールのタグ名を一致させる
3. お問い合わせフォームにはスパム対策（reCAPTCHA）が必要
4. SiteGuard WP Pluginでログイン周りのセキュリティを高める
5. WPvividでバックアップ・サーバーアップができる。修正は本番で直接やらない
