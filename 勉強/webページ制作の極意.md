# Emmet
## HTML
- `<div class="l_container">` → `.l_container` + `Enter`
    - divは省略できるので、そのまま`.`（ドット）から始める
- `<p class="m_cta_txt">` → `p.m_cta_txt` + `Enter`
- `<li class="l_footer-nav_item">` → `li.l_footer-nav_item` + `Enter`
    - 基本的に「`タグ`+`.`+`クラス名`」で全て補完

# CSS

- `font-size: 16px;` → `fz16` + `Enter`
- `margin: 16px 32px;`  → `m16-32` + `Enter`
- `display: block;` → `db` + `Enter`　など


# 単語集
- UX(ユーザーエクスペリエンス)
    - 製品やサービスを使用する際のユーザーの感じる経験や満足度を指す
    - 単に見た目の美しさや機能だけでない
    - ユーザーがどれだけ直感的に操作できるか
    - どれだけ満足できるかなど、心理的・感情的な側面も含めたもの
- UI(ユーザーインターフェース)
    - ユーザーが製品やサービスと対話するための中間的な役割を果たすインターフェースのこと
    - 視覚的な要素の配置、色、サイズなどのデザイン全般
        - ボタン
        - スライダー
        - メニュー
        - アイコンなど、
    - 良好なUIは、直感的で使いやすく、ユーザーの操作を助けるものでなければならない
    - UIのデザインは、ユーザーのタスクを容易に完了させるために最適化される必要がある
    - それによってUX（ユーザー体験）が大きく向上する
