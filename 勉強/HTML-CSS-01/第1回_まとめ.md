# HTML要素の表示形式
変更する場合はCSSの`display`プロパティを使用

## block
- 要素が縦方向に並ぶ表示形式
- 1つの要素が1行分の幅を使う→次の要素は必ず下の行にくる

- 幅や高さ余白などの調整が可能
    - `margin`,`padding`が使える
- 見出し・段落・セクションなど、ページ構成の土台となる要素に使われる。

## inline
- 要素が横方向に並ぶ表示形式
- テキストと同じ行の流れの中に配置されるため、文章の途中でも自然に表示される
- 幅や高さは指定できない
    - 上下方向のmarginも基本的に使えない。
    - paddingは指定できるが、行中の要素であるため、上下方向に指定するとレイアウトが崩れる原因になる
- リンクや文字装飾など、テキストの一部を装飾・操作したい場面で使われる。

## inline-block
- blockとinlineの両方の性質をあわせ持つ表示形式- 要素はinlineと同じく横方向に並ぶ
- block と同じく様々な指定が可能
    - width（幅）
    - height（高さ）
    - margin
    - padding

## 各HTMLタグの表示形式の初期値
|HTMLタグ|表示形式の初期値|
|----|----|
|div|block|
|h1|block|
|section|block|
|article|block|
|header|block|
|main|block|
|footer|block|
|a|inline|
|span|inline|
|img|inline|
|iframe|inline|
|video|inline|

# flex box
## Flexアイテムの性質
- 横並びで表示される
- 親要素に合わせて横幅・高さが伸縮する
- HTMLの記述が表示順に影響しない

親要素にdisplay: flex;を指定すると、子要素が横並びになる
```HTML
<ul class="flexbox">
 <li class="flex-item">要素１</li>
 <li class="flex-item">要素２</li>
 <li class="flex-item">要素３</li>
</ul>
```
```CSS
.flexbox {
 display: flex;
}

.flex-item {
 list-style: none;
 background: #ffbb1e;
 color: #fff;
 padding: 10px;
 margin: 10px;
}
```
- 親要素:flexコンテナ という
- 子要素:flexアイテム という

# 疑似クラス
HTML側にクラス（class="..."）を追加することなく、要素の「特定の状態や条件」に応じてスタイルを適用するCSSの仕組み。
- 操作・状態の指定：マウスが乗った（:hover）、選択中（:focus）などのユーザー操作
- 位置・条件の指定：最初の子要素（:first-child）、偶数番目（:nth-child(even)）などの位置指定

書式
```CSS
セレクタ:擬似クラス名(引数) {
  プロパティ: 値;
}
```
例
```HTML
<ul>
  <li>1行目</li>
  <li>2行目（色が変わる）</li>
  <li>3行目</li>
  <li>4行目（色が変わる）</li>
</ul>
```
```CSS
/* 偶数（2, 4, 6...）番目のliだけ背景色を変更 */
li:nth-child(even) {
  background-color: #f2f2f2;
}
```
## よく使用する疑似クラス
- `:first-child`：親要素内の「最初の子要素」を指定
    - 基本指定：同じ親要素の中で一番最初にある要素に対してスタイルを当てる
        - 例：`li:first-child { color: red; }`
- `:last-child`：親要素内の「最後の子要素」を指定
    - 基本指定：同じ親要素の中で一番最後にある要素に対してスタイルを当てる
        - 例：`li:last-child { margin-bottom: 0; }`
- `:nth-child(n)`：親要素内の「n番目の子要素」を指定
    - 数値指定：指定した順番（数値）の子要素にスタイルを当てる
        - 例：`li:nth-child(3) { font-weight: bold; }`
    - 奇数・偶数指定：`odd`（奇数）や `even`（偶数）でまとめて指定する
        - 例：`li:nth-child(even) { background-color: #f0f0f0; }`
    - 倍数指定：`2n`（2の倍数）や `3n`（3の倍数）などで周期的に指定する
        - 例：`li:nth-child(2n) { color: red; }`
- `:nth-of-type(n)`：指定した要素の種類の中で「n番目の要素」を指定
    - 同一タグのみカウント：他の要素が混ざっていても、指定したタグの種類のみをカウントしてスタイルを当てる
        - 例：`p:nth-of-type(2) { color: blue; }`
- `:hover`：要素にマウスカーソルが乗った（ホバーした）状態を指定
    - ホバー時のスタイル変化：ボタンやリンク上にカーソルが移動した際の挙動を指定する
        - 例：`a:hover { opacity: 0.8; }`
- `:not()`：カッコ内に指定した条件「以外」の要素を指定
    - 特定条件の除外：指定した要素やクラスを除外してスタイルを当てる
        - 例：`.list-item:not(:first-child) { margin-top: 16px; }`
- `:focus`：フォーム入力欄などにフォーカス（選択）が当たった状態を指定
    - フォーカス時の指定：入力フォームが選択状態になった際の枠線などを指定する
        - 例：`input:focus { border-color: #007bff; }`
- `:active`：要素がクリックされている（押されている）瞬間の状態を指定
    - クリック時の指定：ボタンを押している最中の見ためを指定する
        - 例：`button:active { background-color: #333; }`
- `:visited`：訪問済み（過去にクリックした）リンクの状態を指定
    - 訪問済みリンクの指定：アクセス履歴のあるリンクの色などを指定する
        - 例：`a:visited { color: #800080; }`

# よく使うCSSプロパティ
- `color`：テキストの文字色を指定
    - キーワードによる指定：「black」「white」「red」「blue」など、色名を直接指定する
        - 例：`color: red;`
    - 16進数（HEX）による指定：`#` に続けて16進数で指定する
        - 例：`color: #ff0000;`
    - RGB / RGBA値による指定：赤・緑・青の数値や透明度で指定する
        - 例：`color: rgb(255, 0, 0);`
        - 例：`color: rgba(255, 0, 0, 0.5);`
- `font-size`：テキストの大きさを指定
    - px（ピクセル）による指定：固定サイズで指定する
        - 例：`font-size: 16px;`
    - rem / em（相対値）による指定：ルートや親要素のサイズを基準とした割合で指定する
        - 例：`font-size: 1.5rem;`
    - %（パーセント）による指定：親要素の文字サイズに対する割合で指定する
        - 例：`font-size: 100%;`
- `font-family`：テキストのフォント（書体）を指定
    - フォント名の直接指定：使用するフォント名を指定する（スペースを含む場合は引用符で囲む）
        - 例：`font-family: "Helvetica Neue", Arial, sans-serif;`
    - 総称フォント名による指定：ブラウザ標準の汎用フォントファミリーを指定する
        - 例：`font-family: sans-serif;`
- `font-weight`：テキストの太さを指定
    - キーワードによる指定：標準（`normal`）や太字（`bold`）で指定する
        - 例：`font-weight: bold;`
    - 数値による指定：100〜900の数値（100単位）で指定する
        - 例：`font-weight: 700;`
- `line-height`：行の高さ（行間）を指定
    - 単位なしの数値による指定：文字サイズに対する倍率で指定する（推奨）
        - 例：`line-height: 1.5;`
    - pxによる指定：固定の高さで指定する
        - 例：`line-height: 24px;`
- `text-align`：テキストやインライン要素の水平方向の揃え位置を指定
    - `left` / `start`：左揃え（初期値）
        - 例：`text-align: left;`
    - `center`：中央揃え
        - 例：`text-align: center;`
    - `right` / `end`：右揃え
        - 例：`text-align: right;`
- `width`：要素の横幅を指定
    - pxによる指定：固定の横幅を指定する
        - 例：`width: 300px;`
    - %による指定：親要素の幅に対する割合で指定する
        - 例：`width: 50%;`
    - vwによる指定：画面の横幅に対する割合で指定する
        - 例：`width: 100vw;`
- `height`：要素の高さ（縦幅）を指定
    - pxによる指定：固定の高さを指定する
        - 例：`height: 200px;`
    - %による指定：親要素の高さに対する割合で指定する
        - 例：`height: 100%;`
    - vhによる指定：画面の高さに対する割合で指定する
        - 例：`height: 100vh;`
- `padding`：要素の「内側」の余白を指定
    - 一括指定（ショートハンド）：1〜4つの値で上下左右の内側余白を指定する
        - 例：`padding: 10px 20px;`
    - 個別プロパティによる指定：`padding-top` や `padding-left` など方向を個別で指定する
        - 例：`padding-top: 15px;`
- `margin`：要素の「外側」の余白を指定
    - 一括指定（ショートハンド）：1〜4つの値で上下左右の外側余白を指定する
        - 例：`margin: 0 auto;`
    - 個別プロパティによる指定：`margin-bottom` や `margin-right` など方向を個別で指定する
        - 例：`margin-bottom: 20px;`
- `border`：要素の枠線（太さ・種類・色）を一括指定
    - 一括指定（ショートハンド）：「太さ 種類 色」の順で指定する
        - 例：`border: 1px solid #ccc;`
    - 個別プロパティによる指定：`border-width`、`border-style`、`border-color` を個別指定する
        - 例：`border-style: solid;`
- `border-radius`：要素の角を丸める半径を指定
    - pxによる指定：角丸の半径を数値で指定する
        - 例：`border-radius: 10px;`
    - %による指定：要素サイズに対する割合で指定する（正方形に50%で正円）
        - 例：`border-radius: 50%;`
- `overflow`：要素からはみ出たコンテンツの表示方法を指定
    - `visible`：はみ出た部分をそのまま表示する（初期値）
        - 例：`overflow: visible;`
    - `hidden`：はみ出た部分を非表示（切り取り）にする
        - 例：`overflow: hidden;`
    - `scroll`：スクロールバーを表示して閲覧可能にする
        - 例：`overflow: scroll;`
    - `auto`：必要に応じて自動でスクロールバーを表示する
        - 例：`overflow: auto;`
- `box-shadow`：要素に影を付与する
    - 基本指定：「横方向の距離 縦方向の距離 ぼかしの大きさ 影の色」を指定する
        - 例：`box-shadow: 2px 4px 10px rgba(0, 0, 0, 0.2);`
- `background`：背景に関するスタイル（色・画像・位置など）を一括指定
    - 背景色の指定（`background-color`）：背景の色を指定する
        - 例：`background-color: #f0f0f0;`
    - 背景画像の指定（`background-image`）：背景に表示する画像のパスを指定する
        - 例：`background-image: url('image.jpg');`
    - 一括指定（ショートハンド）：色・画像・繰り返し・位置・サイズなどを1行でまとめて指定する
        - 例：`background: #fff url('bg.png') no-repeat center / cover;`
