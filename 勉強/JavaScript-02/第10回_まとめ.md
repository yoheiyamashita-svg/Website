# ハンバーガーメニューを動かす
## 仕様
- ハンバーガーメニューの3本線がバツ印（×）になる
- ナビゲーションが出現する
- ハンバーガーメニューが開いているときは、画面全体のスクロールが固定される（応用）
- もう一度ハンバーガーメニューをクリックすると元に戻る

すべて**クラスの付け外し**で実装する（[[第9回]]のDOM操作の3ステップ）。
1. HTMLから要素を取得する
2. クリックしたときにイベントを発火させる
3. クラスを付け外しする

## JavaScript
```JavaScript
const hamburger = document.querySelector(".js_hamburger");
const navigation = document.querySelector(".js_navigation");
const body = document.querySelector(".js_body");

// ハンバーガーをクリックしたら
hamburger.addEventListener("click", () => {
  // それぞれに対してis-activeクラスを付け外しする
  hamburger.classList.toggle("is-active");
  navigation.classList.toggle("is-active");
  body.classList.toggle("is-active");
});
```
- `function () {}`は`() => {}`（**アロー関数**）と書くこともできる。意味はほぼ同じで、短く書ける
- 1回のクリックで3つの要素のクラスを同時に付け外しし、CSS側で「変化前」と「`.is-active`がついた変化後」を用意しておくことで見た目が変わる

## CSS（変化後の見た目）
```CSS
/* 開いている間はページ全体のスクロールを固定する */
.js_body.is-active {
  overflow: hidden;
}

/* 3本線を×にする */
.js_hamburger-bar {
  transition: top 0.24s, transform 0.24s, opacity 0.24s;
}

.js_hamburger.is-active .m_hamburger-bar:first-child {
  top: 50%;
  transform: translateY(-50%) rotate(135deg);
}

.js_hamburger.is-active .m_hamburger-bar:nth-child(2) {
  opacity: 0; /* 真ん中の線は消す */
}

.js_hamburger.is-active .m_hamburger-bar:nth-child(3) {
  top: 50%;
  transform: translateY(-50%) rotate(-135deg);
}

/* ナビゲーションは普段は透明＋クリック不可にしておく */
.js_navigation {
  opacity: 0;
  pointer-events: none;
  transition: opacity 0.24s;
}

.js_navigation.is-active {
  opacity: 1;
  pointer-events: auto;
}
```
- 上下の線を中央（`top: 50%`）に集めてから逆向きに回転させると×になる（[[第5回]]のハンバーガーメニューの作り）
- `pointer-events: none;`：要素をクリックできないようにする。`opacity: 0`で見えなくしただけだと、透明なナビゲーションがクリックを邪魔してしまうため一緒に指定する
- `body { overflow: hidden; }`でスクロールが固定されるが、iOSでは効かない場合があるので、実務では📎 [こちらの方法](https://zenn.dev/tak_dcxi/articles/bbdb6cd9305ba4)が推奨されている

## 取得した要素を変数に入れるメリット
- 管理がしやすい
- パフォーマンスが上がる（毎回HTMLから探し直さなくてよい）
- `js_`のクラスを使うことで、CSSの都合でクラス名が変わってもJSに影響が出ないようにできる
- どのセレクタがJSで使われているかわかりやすくなる
- `id`ではなくクラスで取得しているのは、CSS設計（詳細度を上げない、[[第4回]]参照）との兼ね合いのため

## 【発展】メニューをクリックしたらページ内のセクションへ移動し、メニューを閉じる
- 同じページ内のセクションに移動するには、移動先の`section`に`id`をつけ（`id="service"`）、ナビゲーションのリンクを`href="#service"`にする
- メニューを閉じるには、すべてのリンクに対してクリックイベントを設定し、`is-active`を外す
```JavaScript
const navLinks = document.querySelectorAll(".l_header-nav_link");

navLinks.forEach((navLink) => {
  navLink.addEventListener("click", () => {
    hamburger.classList.remove("is-active");
    navigation.classList.remove("is-active");
    body.classList.remove("is-active");
  });
});
```
- `querySelectorAll`で複数取得した要素は、`forEach`で1つずつ取り出してイベントを設定する（[[第9回]]の繰り返し処理）
- 閉じるだけなので`toggle`ではなく`remove`を使う

# GSAPの導入
**GSAP**：JavaScriptでアニメーションを簡単に書けるようにするライブラリ。headタグ内で、自分の`main.js`より先に読み込む。
```HTML
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.11.3/gsap.min.js"></script>
<script src="js/main.js" defer></script>
```
📎 [GSAPの導入方法](https://zero-plus.io/media/l_javascript/gsap/#GSAPの導入方法)

## Tween（1つのアニメーション）
| メソッド | 動き |
| --- | --- |
| `gsap.to()` | 今の状態 → 指定した状態（未来）へ動かす |
| `gsap.from()` | 指定した状態（過去） → 今の状態へ動かす |
| `gsap.fromTo()` | 指定した状態（過去） → 指定した状態（未来）へ動かす |

## よく使うプロパティ
| プロパティ | 意味 |
| --- | --- |
| `duration` | アニメーションにかける秒数 |
| `autoAlpha` | 透明度。`opacity`と`visibility`をまとめて操作する（0で完全に非表示） |
| `x` / `y` | X軸／Y軸方向の位置（px） |
| `delay` | 開始までの待ち時間（秒） |
| `onComplete` | アニメーションが完了したときに実行する関数 |

📎 [Tweenを扱う](https://zero-plus.io/media/l_javascript/gsap/#Tweenを扱う)

# スライドイン（Timeline）
## 仕様
- リロードすると、キャッチコピーとサブコピーが左 → 右にふわっと入ってくる
- 時間は0.6秒、コピー → サブコピーの順に時間差をつける

```JavaScript
gsap
  .timeline()
  .from(".js_copy", {
    duration: 0.6, // 0.6秒かけて
    autoAlpha: 0,  // 透明度0の状態から
    x: -100,       // x軸方向に-100pxの位置から
  })
  .from(".js_sub-copy", {
    duration: 0.6,
    autoAlpha: 0,
    x: -100,
  });
```
- `gsap.timeline()`に`.from()`をつなげると、前のアニメーションが終わってから次が始まる → 時間差を簡単につけられる
- 📎 [Timelineを扱う](https://zero-plus.io/media/l_javascript/gsap/#Timelineを扱う)

## 【発展】GSAPを使わずに同じ動きをつける
```JavaScript
const mainCopy = document.querySelector(".js_copy");
const subCopy = document.querySelector(".js_sub-copy");

// ページの読み込みが完了したら
window.addEventListener("load", () => {
  mainCopy.classList.add("is-active");
  subCopy.classList.add("is-active");
});
```
```CSS
.js_copy,
.js_sub-copy {
  opacity: 0;
  transform: translateX(-100px);
}

.js_copy.is-active,
.js_sub-copy.is-active {
  opacity: 1;
  transform: translateX(0);
  transition: 0.6s;
}

.js_sub-copy.is-active {
  transition-delay: 0.6s; /* 時間差 */
}
```
- `window`の`load`イベントで「ページの読み込みが完了したとき」に処理を実行できる

# オープニングアニメーション
## 仕様
- 読み込んだときに、オープニングのテキストがふわっと入ってくる
- オープニングアニメーションが完了したら、オープニング画面が消える
- 消えた後、キャッチコピーとサブコピーが順番に左 → 右にふわっと入ってくる
- +α：アニメーション中はスクロールできないようにする
- 応用：一度ローディングしたら、それ以降はローディングしない

```JavaScript
const opening = document.querySelector(".js_opening");

function OpeningAnime() {
  // アニメーション中はスクロールを固定（ハンバーガーで作ったoverflow: hiddenを再利用）
  body.classList.toggle("is-active");

  gsap
    .timeline()
    .from(".js_opening-txt", {
      duration: 1.2,
      autoAlpha: 0,
      y: 40, // 40px下から
    })
    .to(".js_opening", {
      autoAlpha: 0,
      duration: 0.6,
      delay: 1.2,
      // アニメーションが完了したらスクロール固定を解除
      onComplete: function () {
        body.classList.toggle("is-active");
      },
    })
    // スライドインのアニメーション
    .from(".js_copy", {
      duration: 0.6,
      autoAlpha: 0,
      x: -100,
    })
    .from(".js_sub-copy", {
      duration: 0.6,
      autoAlpha: 0,
      x: -100,
    });
}

OpeningAnime(); // 関数呼び出し
```
- オープニングのテキストは`.from()`（下からふわっと出す）、オープニング画面は`.to()`（今の状態から透明にして消す）
- タイムラインを使うことで、複数のアニメーションの順番をまとめて管理できる

## 【応用】2回目以降はオープニングを表示しない（sessionStorage）
```JavaScript
function webStorage() {
  if (sessionStorage.getItem("access")) {
    // 2回目以降のアクセス：アニメーションは実行せず、オープニングを消しておく
    opening.classList.add("is-active");
    body.classList.add("is-active");
  } else {
    // 初回アクセス：目印を保存してアニメーションを実行
    sessionStorage.setItem("access", 0);
    OpeningAnime();
  }
}

webStorage();
```
- `sessionStorage`：ブラウザのタブを閉じるまでの間、データを保存しておける仕組み
    - `setItem(キー, 値)`で保存、`getItem(キー)`で取り出す
- 「保存した目印があるか」で初回かどうかを判定し、処理を出し分けている
- 📎 [sessionStorage（MDN）](https://developer.mozilla.org/ja/docs/Web/API/Window/sessionStorage)

# 本日のまとめ
1. JavaScriptのアニメーションは「要素を取得 → イベントを指定 → クラスを付け外し」が基本（ハンバーガーメニュー）
2. CSS側で変化前と`.is-active`の変化後を用意しておき、JSはクラスの付け外しのタイミングだけを管理する
3. GSAPは`gsap.to()`／`from()`／`fromTo()`の**Tween**で1つの動きを作る
4. `gsap.timeline()`を使うと、複数のアニメーションの順番や時間差をまとめて管理できる
5. `onComplete`でアニメーション完了後の処理、`sessionStorage`で初回だけの処理を作れる
