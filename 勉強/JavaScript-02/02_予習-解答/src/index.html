  • ・STEP2：特定の要素を取得する
  • 「jsFindItem4」という定数名で定義してください
  • 定数に代入する要素は、STEP1で定義した「jsFind」という定数を使用して、「.find_list-item-4」という要素を取得してください
  • ※ヒント：「.jsFind」の中から「.find_list-item-4」を取得するという記述にしてください
  • ※ヒント：要素を取得する際にはメソッドを使用してください
  • ・STEP3：STEP2で作成したをfindListItem4用いて、要素の色を「#f00」に変更してください
  • ※ヒント：要素の色を変更する際には、styleプロパティを直接追加するメソッドを使用してください
