## 1. Notionページから取得するもの
Notionは通常のWeb取得では本文が読めないため、ブラウザで開いて読む。
「▶︎」のトグルは閉じていると中身が見えないので、すべて開いてから読む。

| 取得するもの | ページ内の場所 | 例（JavaScript-04） |
| --- | --- | --- |
| 回番号 N | プロパティ「Lesson」の数字 | `12` |
| フォルダ名 | ページタイトル | `JavaScript-04` |
| 素材 | 下の「2. 素材」を参照 | |

出力先は `勉強/{フォルダ名}/第{N}回_まとめ.md` とする。
フォルダが存在しないときは、作らずに質問する。

## 2. 素材
次の3つを読む。
- Notionページ本文（予習課題・授業・復習課題のトグル内を含む）
- ページ内にある外部の参考記事（zero-plus.io/media の記事、公式ドキュメントなど）
- 「予習課題ポイント」「復習課題ポイント」のNotion子ページ

次のリンクは読まない。
- 学習方法の記事（「予習課題の効率化テクニック」「6割理解で進める復習メソッド」など）
- ZeroPlus Portal、教材のダウンロード（Google Drive）、アンケート、講義修了テスト
- 「今週のアクション」「告知」「次回の授業について」など、授業内容と関係ないもの
- Figmaなど、次回以降の準備の案内

## 3. 構成
`HTML-CSS-01/第1回_まとめ.md` と同じ構成にする。
- 最初に `# 第N回の目標` を置き、授業の目標（Notionの「授業内でのゴール」）を太字の箇条書きで書く
- その後はトピックごとに `#` 見出しを立て、`##`・`###` で細かく分ける
- 各トピックは「それが何か（概念） → 書き方・プロパティ」の順で書く
- 演習の仕様・ヒント・模範解答はまとめに移さない。演習で使った知識（プロパティ・書き方）だけを各トピックに入れる

## 4. 書き方のルール
- 常体（〜である・〜する）で、説明は短く箇条書き中心にする
- プロパティ・タグ・値の一覧は「名前｜意味」の表にまとめる
- コード例には言語名つきのコードブロックを使い、行ごとに何をしているかコメントを書く
- 参考記事は `📎[タイトル](URL)`、他の回への参照は `[[第N回]]` で書く

## 5. 内容の範囲
- 素材に書かれている内容だけでまとめる。素材にない情報を自分の知識で補わない
- 素材だけでは意味が分からない・矛盾している箇所があれば、推測で埋めずに質問する

## 6. 進め方
1. 素材を読み、次の3点を提示して確認を取る
   - 出力先のパス
   - 読んだ参考記事のURL一覧
   - 見出し構成（`#`〜`##`）
2. OKが出たら本文を書き、出力先に保存する
