# デザインカンプとは
- デザインの完成形。ワイヤーフレームに、画像・配色・あしらいを加えて作る（[[第14回]]の制作フロー参照）
- 作る流れ：画像を入れる → 配色する → あしらいを作る

# 画像を入れる
| 入れ方 | 動き | コーディングでいうと |
| --- | --- | --- |
| 作ってある図形に入れる | 図形の形に切り抜かれる（クリッピングマスク） | `div`に`background`で画像を入れるイメージ |
| 画像をそのまま配置する | 切り抜かれない | `img`タグのイメージ |

複数の画像をまとめて入れる手順
1. `shift + command + K`（Win：`shift + ctrl + K`）でフォルダを開く
2. 必要な画像を`shift`を押しながら選ぶ
3. Figma上で、入れたい図形を順番にクリックして当てはめる

- 📎 [Figmaで複数の画像をまとめて追加するショートカット](https://www.unprinted.design/articles/figma-shortcut-add-multiple-images/)
- 【+α】📎 [Unsplash（Figmaプラグイン）](https://note.com/fork_573/n/n5d187b9b1ced)：無料の高品質な写真素材を、Figmaから離れずに検索・挿入できる。ダミー画像でレイアウトを確認したいときに便利

# 配色
## 基本は3色
| 色 | 割合 | 役割 |
| --- | --- | --- |
| ベースカラー | 約70% | 背景の色。白・黒・灰色などの無彩色が一般的（おすすめは白`#FFF`） |
| メインカラー | 約25% | サイトのイメージカラー。指定がなければターゲットや雰囲気に合わせて決める（例：青は信頼感） |
| アクセントカラー | 約5% | 「お問い合わせ」など、サイトの目的に直結する箇所だけに使う |

- 色を増やしすぎると混乱するので、まず3色に絞る
- クライアントの指定があれば、ロゴやアイコンから色を取り出す

## 自分の頭だけで考えない
- **色相環**を使う
    - アクセントカラー：色相環で向かい合う**補色**（例：オレンジと青）。互いに同化せず、鮮やかに見える
    - サブカラー：色相環で隣り合う**同系色**
- 補色を使うときは、**ハレーション**（色がちらついて見づらくなること）に注意する
- 配色ツール：Coolors（Figmaプラグインもあり、パレットをFigmaに登録できる）、Adobe Color CC、colorsupplyyy、Pigment、NIPPON COLORS など
- 📎 [Webデザインの配色のコツを学ぼう](https://zero-plus.io/media/l_web-design/web%e3%83%87%e3%82%b6%e3%82%a4%e3%83%b3%e3%81%ae%e9%85%8d%e8%89%b2%e3%81%ae%e3%82%b3%e3%83%84%e3%82%92%e5%ad%a6%e3%81%bc%e3%81%86_figma/)／[色と配色の基本](https://baigie.me/officialblog/2021/01/27/color_theory/)／[蛍光色・グラデーションの注意点](https://b-risk.jp/blog/2021/06/beginner_design_color/)

## Figmaでの色の変え方
1. 色を変えたい要素を選ぶ（グループの中の要素を選ぶときは注意）
2. 塗りパネルの「スタイル」から、変えたい色をクリックする

# コンポーネント
繰り返し使うパーツ（ヘッダー、フッター、ボタン、CTAなど）を管理し、編集しやすくする機能（[[第14回]]も参照）。

| 用語 | 意味 |
| --- | --- |
| メインコンポーネント | 元になるもの（親） |
| インスタンス | メインコンポーネントの複製（リンクしている子） |

| 編集する対象 | 反映される範囲 |
| --- | --- |
| メインコンポーネント | すべてのインスタンスに反映（スタイルも文字も） |
| インスタンス | そのインスタンスだけ。変更した部分はメインとのリンクが切れ、以後メインを直しても反映されない |

作り方
1. メインコンポーネントをまとめるフレーム（名前は「コンポーネント」）を作る
2. コンポーネントにする要素を作る
3. 要素を選び、右クリック →「コンポーネントの作成」、または右上のアイコン、またはショートカット（Mac：`command + option + K`／Win：`ctrl + alt + K`）
4. メインコンポーネントは、なくさないようにフレームの中に置いておく

- 呼び出すときは、左の「アセット」パネルからドラッグ＆ドロップする。配置したものはインスタンスになる
- コンポーネントを使うと作業が早くなり、親を変えれば同じ要素を一気に変更できる
- 📎 [Figmaのコンポーネント機能を学ぼう](https://zero-plus.io/media/l_web-design/figma_component/)

# あしらい
## あしらいとは
- デザインの**装飾**のこと。デザインにメリハリをつける（対比を生む）のが主な目的
- 効果
    - 情報を整理しやすくする
    - 大事な情報を伝えやすくする
    - 見えにくい情報を見やすくする
    - サイトの雰囲気を演出する

## あしらいの種類
| 種類 | 例 | 注意点 |
| --- | --- | --- |
| 線 | 目立たせたい文字の下線、小見出しの下の線 | 線は「添えるだけ」。主役にしない |
| アイコン | 項目・リンク・ボタンに添える目印 | リンクだと気づいてもらう目的で使う |
| 装飾用のテキスト | 見出しの後ろの大きく薄い英字 | ― |
| 装飾用の画像 | 手書き文字の画像で柔らかさを出す | サイトの雰囲気に合わせる |
| 座布団 | 文字を色付きの四角で囲んで見やすくする | 座布団と上に載せる要素の色の組み合わせに注意 |
| 影 | ボタンなどクリックできる箇所 | ボタンには薄く入れる |
| フィルター | KVや画像の上に半透明の色を重ねる | ― |

- あしらいはパターン。参考サイトを真似てアレンジすればよく、一から作る必要はない。自分だけのネタ帳を作って集める
- デザインには意図を持つ。いろいろなデザインを見る（📎 [SANKOU!](https://sankoudesign.com/)）
- Figmaでは、グループの中の要素を選んだ状態で作成ツールに持ち替えてクリックすると、グループの中に直接要素を作れる
- レイヤーの重なり順：`ctrl + [`（背面へ）、`ctrl + ]`（前面へ）。`[`・`]`単体で最背面・最前面
- 📎 [Webデザインのあしらいを学ぼう](https://zero-plus.io/media/l_web-design/ornaments/)／[gaz mix：凝ったあしらい](https://recruit.gaz.design/blog/20220114)／[物足りなさを解消する方法11選](https://konsuki.com/8127/)／[少しのアイデアで大きく変わるWebデザインのコツ](https://grow-group.jp/archives/8685/)／[あしらいの簡単テク](https://webac-plus.com/column27.html)／[コンセプト設計について](https://japan-design.jp/design/0061/)（+α）

# ジャンプ率
- 要素同士の**大きさの比率**のこと
    - 大きさの差が大きい → ジャンプ率が高い（優先順位がはっきりする）
    - 差が小さい → ジャンプ率が低い（要素の区別がつきにくい）
- 大きい要素ほど優先順位が高い（例：キャッチコピー ＞ 本文）
- 目的は、情報に優先順位をつけることと、情報を見やすくすること

| 対象 | 例 |
| --- | --- |
| 見出しと文章 | 見出しを大きくして「見出し ＞ 文章」の順にする |
| 表のテキスト | 「数字 ＞ 単位」のように差をつける |
| 文章の中 | 重要な部分を目立たせる |
| 画像 | 最初に見せたい画像を大きくする |

- テキストを打ち込むだけでは、ジャンプ率は自然には生まれない。作る前に、数字・単位・強調したい語句などの情報を整理して分けておく
- 📎 [デザインのジャンプ率を学ぼう](https://zero-plus.io/media/l_web-design/learn-jump-ratio/)

# レイアウトの考え方
- 0から考えるのは難しい。たくさんのサイトを見て、「この部分はこの配置を元にやってみよう」というものを1つ見つけて真似する
- パーツごとの参考は📎 [Parts.（パーツ別Webデザイン集）](https://partsdesign.net/)で探せる
- 📎 [定番レイアウトパターン6選](https://creator.levtech.jp/tips/article/52/)／[レイアウトの基本と4つのポイント](https://webac-plus.com/column3.html)／[レイアウトデザインの視点を増やす](https://note.com/harahiroshi/n/n3af079dc17e9)

## デザインはどこまで詰める？
| 体制 | 詰める度合い |
| --- | --- |
| デザイナーとコーダーが同じ人 | px単位のこだわりは必須ではない。ただし第三者に見せるときは質が必要なので、できる限り完成形に近づける。サイズまで決めておくと、コーディングが楽になる |
| デザイナーとコーダーが別の人 | pxまでしっかり決めるのがベスト。コーダーがコーディングに集中できるよう作り込む |

# 【Challenge】Figmaの便利な機能
## レイヤー名を一括で変える
変えたいレイヤーをすべて選んで`command + R`（Win：`ctrl + R`）を押すと、まとめて名前を変えられる。

| やりたいこと | 方法 |
| --- | --- |
| 全部同じ名前にする | 「変更後の名前」に入力する |
| 連番をつける | 「昇順↑」を押すと末尾に`$nn`が入る（開始番号も変えられる） |
| 今の名前に文字を足す | 「現在の名前」を押すと`$&`が入るので、前後に文字を足す |
| 名前の一部を置き換える | 上段に置換前、下段に置換後の文字を入れる |

- レイヤー名の付け方のルールは[[第14回]]を参照

## プロトタイプで動きを再現する
プロトタイプは、画面遷移などを完成品に近い形で再現する機能。見た目だけでなく使い心地まで確認できる。右上の再生ボタンで動きを確認する。

| 再現する動き | 設定 |
| --- | --- |
| ヘッダーの追従 | ヘッダーを選び、「プロトタイプ」→「スクロールの操作」の「位置」を「追従（上端で停止）」にする（「固定」は`fixed`、「追従」は`sticky`に相当） |
| ハンバーガーメニューの開閉 | 「位置」を「上中央」、「外部をクリックしたときに閉じる」にチェック。アニメーションは「ディゾルブ」＝フェードイン、「ムーブイン」＝スライドイン（📎 [Figmaでハンバーガーメニュー](https://krtyrk.com/design/figma-hamburger.html)） |
| ボタンのホバー | ボタンのバリアントを「State」＝`default`／`hover`で作り、マウスが重なったら切り替わるように設定（📎 [Figmaでホバーを表現する](https://crepro-media.com/pickup/figma-hover/)） |
| トグルスイッチ | タップでつまみがスライドしてオン・オフが切り替わる（📎 [トグルの作り方](https://note.com/ankokakemelon/n/nbbe195ea9c56)） |
