# 変数
## 変数の宣言と代入
変数を定義する際には必ず「変数の宣言」を行う。
「宣言のキーワード（`let`／`const`） 変数名 = 値;」の形で変数を宣言し、値を代入する（授業ではキーワードの部分を「変数の型」と呼んでいる）。
- 変数は、数値や値などを入れておく箱のようなもの。何度も使う値をまとめておける（CSS変数と同じ考え方）
- `=`は「等しい」ではなく「右の値を左の変数に**代入**する」という意味
    - 「等しい」を表すときは`==`か`===`を使う
- `console.log()`：かっこ内の値をコンソール画面に表示する。動作確認に使う
    - VSCodeでは「log」と打って↓を1回押し、Enterで出せる
```JavaScript
let score = 80;
console.log(score);
```

## 再代入
一度宣言した変数に別の値を入れ直すことを「再代入」と呼ぶ。「再定義（もう一度`let`などをつけて宣言し直すこと）」とは別物なので混同しないように注意する。
```JavaScript
let score = 80;
console.log(score);

// 再代入
score = 95;
console.log(score);
```

| 書き方 | 呼び方 |
| --- | --- |
| `let fruit = "りんご";` | 宣言（定義） |
| `fruit = "ぶどう";` | 再代入 |
| `let fruit = "りんご";` の後に `let fruit = "ぶどう";` | 再宣言 → **エラー**（同じ名前を2回宣言している） |

## 文字列と変数の書き分け
- 文字列は`"`や`'`で囲う。変数名は囲わない
```JavaScript
let fruit = "りんご";

console.log(fruit);   // 「りんご」（変数の中身）
console.log("fruit"); // 「fruit」（ただの文字列）
```
- `"`と`'`はどちらでもよい。JSではシングルクォートが使われることが多い（HTMLのダブルクォートと区別するため。ESLintや一般的なスタイルガイドでも推奨されることが多い）。大事なのは**統一すること**
    - 文字列の中で`'`を使うときは、外側を`"`にする（例：`"That's a good idea"`）
- `;`（セミコロン）は処理の終わりを表す（文章の「。」）。VSCodeの拡張機能📎 [Prettier](https://ralacode.com/blog/post/vscode-prettier/)で自動で入れられる

## 数値と文字列の違い
```JavaScript
const a = 50;   // 数値
const b = "50"; // 文字列

console.log(a + 2); // 52（足し算）
console.log(b + 2); // 502（文字として連結される）
```
- コンソールでは、数値は紫色、文字列は白色で表示される

## テンプレートリテラル
文字列の中に変数を埋め込む書き方。`` ` ``（バッククォート）で囲い、変数を`${}`に入れる。
```JavaScript
const age = 20;
console.log(`${age}歳は、成人です`);     // テンプレートリテラル
console.log(age + "歳は、成人です");     // +で連結しても同じ
```
- `'`や`"`ではなく`` ` ``で囲うので注意
- 変数を1つ出すだけなら、テンプレートリテラルは使わなくてよい（`console.log(i);`で十分）
- 「これは何？」と思ったら、「js ドルマーク 括弧」のように言語化して検索する（📎 [テンプレートリテラルとは](https://zenn.dev/yamap_web/articles/4aa79f2a71e4b3)）

## let・const・varの違い
| 種類 | 呼び方 | 再代入 | 再定義 |
| --- | --- | --- | --- |
| let | 変数 | ⭕️ | ❌ |
| const | 定数 | ❌ | ❌ |
| var | （古い書き方） | ⭕️ | ⭕️ |

昔は`var`が主流だったが、再定義まで可能なため長いコードや複数人での開発で意図しない上書きが起きやすかった。そこで「再代入はしたいが再定義はしたくない`let`」「再代入すらしたくない`const`」が使われるようになり、現在は`let`・`const`が主流になっている。
- 古いサイトで`var`が使われていたら、`let`や`const`に書き換えるとよい
- `const`は1度定義すると中身を変えられない（意外と便利）。これが`let`との大きな違い

### constとletどちらを使う？
- 基本は`const`を使い、再代入が必要なものだけ`let`にする
- 最初はどれが再代入が必要か分からないので、慣れるまでは全部`let`でもよい
- 実際は1から書くより、調べて出てきたコードをコピペすることが多い。最初から`const`か`let`で書かれているので、自分で判断する場面はあまりない

### 変数を使う理由
- 変数を定義しても、ページの見た目には直接影響しない。変数を使わなくてもアニメーションは作れる（CSS変数と同じ）
- JSで要素を操作するときは、毎回`document.querySelector(".クラス名")`を書く必要がある
    - 何回も書くとコードが長くなる
    - クラス名が変わったとき、すべての箇所を書き換える必要がある
- `const box = document.querySelector(".js_box");`のように変数に入れておけば、以降は`box`と書くだけで操作できる

# 条件分岐（if文）
## 基本の書き方
```JavaScript
if (条件1) {
  // 条件1が真のときの処理
} else if (条件2) {
  // 条件2が真のときの処理
} else {
  // どちらにも当てはまらないときの処理
}
```
条件は上から順番に判定されるため、範囲を絞り込むような条件を並べるときは判定の順序に注意する（最も厳しい条件を先に書くなど）。

| 書き方 | 日本語にすると |
| --- | --- |
| `if` | もし〇〇だったら、〜〜する |
| `else if` | そうじゃなくて△△だったら、〜〜する |
| `else` | それ以外だったら、〜〜する |

処理の進み方
1. `()`内の条件を確認する
2. 当てはまったら、`{}`内の処理を実行する
3. 当てはまらなかったら、次の`()`内の条件を確認する（1に戻る）

押さえるポイント：構文（書き方の型）、処理の仕組み、演算子、`else`と`else if`の使い分け

### 条件が狭いものから書く
```JavaScript
const score = 100;
if (score >= 80) {
  console.log("合格です！");
} else if (score >= 60) {
  console.log("もう少しで合格です！");
} else if (score >= 30) {
  console.log("もう少し頑張りましょう！");
} else {
  console.log("学習範囲を反復しましょう！");
}
```
- `score >= 30`を先に書くと、90点でも最初の条件に当てはまってしまう

### elseで済むところはelseにする
```JavaScript
if (age < 20) {
  console.log("未成年です");
} else {             // else if (age >= 20) でも間違いではないが、
  console.log("成人です"); // age < 20 でなければ20以上が確定しているのでelseの方がシンプル
}
```

## 演習：年齢で出し分ける
```JavaScript
const age = 20;

if (age < 0 || isNaN(age)) {
  console.log("正しい値を入力してください。");
} else if (age < 20) {
  console.log("あなたは20歳未満です。");
} else if (age >= 20) {
  console.log("あなたは20歳以上です。");
} else {
  console.log("正しい値を入力してください。");
}
```
- `isNaN()`：値が数値でない（Not a Number）ときに`true`を返す関数。チャレンジ問題で「数値かどうか」の判定に使った
- `||`（または）で、2つの条件のどちらかに当てはまれば実行されるようにしている

## switch文
1つの値（式）が、どの候補と一致するかで処理を分けたいときに使う。`if〜else if`を何個も並べるより見やすくなる場合がある。
- `case`ごとに`break;`を書かないと、次の`case`の処理まで続けて実行されてしまう
- `case`を続けて書くと「AまたはB」の条件にできる
- どれにも当てはまらないときは`default`の処理が実行される

```JavaScript
switch(式){
 case 比較対象1:
  //式が比較対象1と一致した場合に実行する処理
  break;

 case 比較対象2:
  //式が比較対象2と一致した場合に実行する処理
  break;

 case 比較対象3:
 case 比較対象4:
  //式が比較対象3または比較対象4と一致した場合に実行する処理
  break;

 default:
  //どのcaseにも一致しなかった場合に実行する処理
  break;
}
```

# 関数
## 関数とは
一連の処理をひとまとめにしたもの。「何かを受け取って、何かを返す」マシーンのようなイメージ。
- 同じ処理を何度も使い回したいとき
- 任意のタイミングで処理を実行させたいとき

に使う。

- 全自動洗濯機のイメージ：「洗剤を入れる・洗う・すすぐ・脱水する」という多くの処理を、ボタン1つでまとめて動かせる
- 押さえること
    1. 関数の中には処理が入っている
    2. スイッチを入れる（呼び出す）まで動かない
- メリット：何度も使う処理を毎回書くと読みにくく、修正も大変。関数にまとめればどちらも解決する。引数で動きのバリエーション（右から出る・下から出るなど）も変えられる

## 定義と呼び出し
```JavaScript
// 関数の定義
function 関数名(引数) {
  // 一連の処理
}

// 関数の呼び出し
関数名(渡す値);
```

## 引数と返り値（戻り値）
引数は関数に渡す「材料」。返り値は処理の結果として関数から返ってくる値で、`return`で指定する。引数と返り値はセットで使われることが多い。
```JavaScript
function introduce(name) {
  const message = name + "さん、こんにちは";
  return message;
}

console.log(introduce("山田"));
```

- `function`は関数を作るときの決まり文句。関数名・引数名は好きな名前でよい
- 引数：同じ命令の一部を変えて使い回したいときに使う「材料」。変えたい部分が複数あれば、引数を増やす
- 返り値：自動販売機のように、関数の結果を呼び出し元に返す値。関数の外で結果を使いたいときに`return`で書く

```JavaScript
// panmanという関数を宣言する。foodとtypeという材料（引数）を受け取る
function panman(food, type) {
  // nameという箱を用意して、foodとtypeを足したものを代入する
  let name = food + type;

  // 出来上がったものを関数の外に返す
  return name;
}

// 関数のスイッチを押して動かす。入れたい材料をここで渡す
console.log(panman("あん", "パンまん"));     // あんパンまん
console.log(panman("メロン", "パンなちゃん")); // メロンパンなちゃん
console.log(panman("ジャム", "おじさん"));    // ジャムおじさん
```

### 返り値は電卓の「=」
- 「3+5」と押しても、「=」を押さないと結果は出ない。関数で「3+5」を作り、`return`で「=」を押すイメージ
- 関数の`{}`の中は別世界で、外からは中の変数を使えない（スコープ）。だから`return`で外に出す
- 関数名や返す変数の名前は、処理の内容が分かるものにする（CSSのクラス名と同じ考え方）
- 📎 [関数の定義・呼び出し・戻り値の基本](https://tagnote.net/javascript/function/)

### 関数の書き方は3種類
```JavaScript
// 関数宣言
function greeting(name) {
  console.log(`${name}さん、こんにちは`);
}

// 関数式
const greeting2 = function (name) {
  console.log(`${name}さん、こんにちは`);
};

// アロー関数
const greeting3 = (name) => {
  console.log(`${name}さん、こんにちは`);
};

greeting("佐藤"); // 呼び出し
```
- どれでも同じ動き。今すぐ暗記しなくてよく、記事を見ながら真似して書ければよい
- 書き方のルールは会社やチームによって違う。「忘れたら調べればよい」と考える

## 演習：2つの数を足す関数
```JavaScript
function sum(a, b) {
  const result = a + b;
  return result;
}

console.log(sum(4, 8)); // 12
```
- 関数作成の流れは「関数の定義（マシーンを作る）→ 中身の処理を記述（動きを設定）→ 関数の呼び出し（スイッチON）」
- 同じ動きをしていればどんな書き方でもよいが、不必要に長い場合は改善の余地がある

# DOM操作
## DOMとは
DOM（Document Object Model）とは、HTMLの要素をプログラムから自由に操作するための仕組み。JSでHTMLの要素を取得し、操作することを「DOM操作」と呼ぶ。JavaScriptでHTML・CSSを操作することによってアニメーションを作り出すことができる。
- 簡単にいうとHTMLの情報のこと
- `document`には、HTML全体の情報が入っている
📎 [DOMとは（参考）](https://eng-entrance.com/what-is-dom)

## 要素の取得
### `document.getElementsByClassName()`
- DOMは配列で取得される（正確には配列に似た`HTMLCollection`という形。`[0]`のように番号で取り出せる）
- "class-name"のように、class属性名をそのまま指定する
```JavaScript
document.getElementsByClassName("class-name");

const className = document.getElementsByClassName("class-name");
console.log(className[0]);
console.log(className[1]);
console.log(className[2]);
```
### `document.getElementById()`
- DOMはそのまま取得される
- "id-name"のように、id属性名をそのまま指定する
```JavaScript
document.getElementById("id-name");

const idName = document.getElementById('id-name');
console.log(idName);
```
### `document.querySelector()`（1つの要素を取得）
- そのまま取得される
- CSSセレクタと同様にclass属性なら.（ドット）、id属性なら#（シャープ）が必要
- 複数ある場合は、最初の要素が取得される
```JavaScript
document.querySelector(".class-name");
document.querySelector("#id-name");
document.querySelector("div");
document.querySelector("div p");

const queryClassName = document.querySelector('.class-name');
const queryIdName = document.querySelector('#id-name');
console.log(queryClassName);
console.log(queryIdName);
```
### `document.querySelectorAll()`（複数の要素を取得）
- 配列で取得される（正確には配列に似た`NodeList`という形。`forEach`で1つずつ処理できる）
- CSSセレクタと同様にclass属性なら.（ドット）、id属性なら#（シャープ）が必要
```JavaScript
document.querySelectorAll(".class-name");
document.querySelectorAll("div");
document.querySelectorAll("div p");

const queryAllClassName = document.querySelectorAll('.class-name');
const queryAllIdName = document.querySelectorAll('#id-name');

console.log(queryAllClassName);
console.log(queryAllIdName);
```

```JavaScript
const box = document.querySelector(".sample_box");
console.log(box);
```

## イベントとクラス操作
`addEventListener`でクリックなどのイベントを検知し、`classList`メソッドでクラスの付け外しを行うのが基本の流れ。
```JavaScript
const box = document.querySelector(".sample_box");

box.addEventListener("click", function () {
  box.classList.toggle("is-active");
});
```

| メソッド | 動き |
| --- | --- |
| `classList.add()` | クラス属性を追加する |
| `classList.remove()` | クラス属性を削除する |
| `classList.toggle()` | クラス属性を付け外しする（ついていれば外す、なければ付ける） |

見た目の変化はCSS側（`.is-active`がついたときのスタイル）にあらかじめ定義しておき、`transition`を組み合わせるとアニメーションになる。

### DOM操作の型
一言一句書けるようになる必要はない。型をメモしておき、`[ ]`の部分を書き換えて使う。
```JavaScript
// 取得したい要素を、好きな名前の変数に入れる
const [変数名] = document.querySelector(".[取得したいクラス名]");

// 変数に対してイベントが起きたら
[変数名].addEventListener("[イベント]", function () {
  // クラス名を追加する
  [変数名].classList.add("[追加したいクラス名]");
});
```
- `function () {}`は`() => {}`（アロー関数）でもよい
- 見た目の変化は、ほとんど「クラス名の付け替え」で起こしている
    - CSS：変化後の見た目を用意しておく
    - JS：要素を取得 → 変化のタイミングを指定 → クラス名（`is-active`など）を付ける

# 【+α】繰り返し処理
授業内では扱わなかったが、同じ処理を繰り返すための構文としてfor文・while文・forEach文がある。余裕があれば予習・復習課題のチャレンジ問題で触れておくとよい。
- **for文**：繰り返す回数があらかじめ決まっている処理向き
- **while文**：条件を満たす間だけ繰り返したい処理向き
- **forEach文**：配列の要素を1つずつ取り出して処理したいときに使う

```JavaScript
// while文：numが15以下の間、繰り返す
let num = 1;
while (num <= 15) {
  console.log(num);
  num++;
}

// for文：(初期値; 条件; 増やし方) を1行で書く
for (let i = 1; i <= 15; i++) {
  console.log(i);
}
```

## 演習：FizzBuzz
```JavaScript
for (let i = 1; i <= 30; i++) {
  if (i % 15 == 0) {
    console.log("FizzBuzz!!");
  } else if (i % 3 == 0) {
    console.log("Fizz");
  } else if (i % 5 == 0) {
    console.log("Buzz");
  } else {
    console.log(i);
  }
}
```
- 割った余り（`%`）が0かどうかで、倍数であるかを判定している
- JSの処理は上から進むため、最も条件が厳しい「15の倍数」を一番最初の条件にする

# スコープ
変数を使える（参照できる）範囲のこと。
- **グローバルスコープ**：関数や`{}`の外で宣言した変数。どこからでも参照できる
- **ローカルスコープ**：関数や`{}`（ブロック）の中で宣言した変数。その中でしか参照できない
```JavaScript
const siteName = "ZeroPlus"; // グローバルスコープ

function showName() {
  const message = "こんにちは"; // ローカルスコープ（この関数の中だけ）
  console.log(message + siteName); // どちらも使える
}

showName();
console.log(message); // エラー：関数の外からは参照できない
```
- `let`・`const`は`{}`（if文やfor文のブロック）の中で宣言すると、そのブロックの外では使えない
