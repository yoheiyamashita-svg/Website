# JavaScriptとは
Web制作におけるJavaScriptの役割は、基本的には「Webサイトに動きをつける」こと（ふわっとしたアニメーション、ハンバーガーメニューの開閉など）。
- ユーザーが入力した数値に応じて計算する
- クリックした項目によって表示を切り替える
- スクロールやクリック、リロードをきっかけにアクションを起こす

⇒ **結論：CSSだけでは実現できない、ユーザーの操作に応じた「動的」な処理ができる。**

※JavaScriptはWeb制作に限らず、Webアプリ・スマホアプリなどフロントエンドからバックエンドまで幅広く使われる言語でもある。

# JavaScriptを書く準備
## ①ファイルを用意する
拡張子は`.js`。多くの現場では`js`フォルダの中にjsファイルをまとめる構成が一般的（例：`project/js/main.js`）。

## ②読み込み場所を記述する
HTMLファイルに「相対パス」で「scriptタグ」を使って読み込む（headタグ内に書くことが多い）。
```HTML
<script src="js/main.js"></script>
```

## ③defer属性をつける
DOM（HTMLの要素）を読み込み終えてからJSを実行するよう指示する属性。表示速度の面でもメリットがあるため、基本的につけておく。
```HTML
<script src="js/main.js" defer></script>
```

# 変数
## 変数の宣言と代入
「型 変数名 = 値;」の形で変数を宣言し、値を代入する。
```JavaScript
let score = 80;
console.log(score);
```

## 再代入
一度宣言した変数に別の値を入れ直すことを「再代入」と呼ぶ。「再定義（もう一度`let`などをつけて宣言し直すこと）」とは別物なので混同しないように注意する。
```JavaScript
let score = 80;
console.log(score);

// 再代入
score = 95;
console.log(score);
```

## let・const・varの違い
| 種類 | 呼び方 | 再代入 | 再定義 |
| --- | --- | --- | --- |
| let | 変数 | ⭕️ | ❌ |
| const | 定数 | ❌ | ❌ |
| var | （古い書き方） | ⭕️ | ⭕️ |

昔は`var`が主流だったが、再定義まで可能なため長いコードや複数人での開発で意図しない上書きが起きやすかった。そこで「再代入はしたいが再定義はしたくない`let`」「再代入すらしたくない`const`」が使われるようになり、現在は`let`・`const`が主流になっている。

# 条件分岐（if文）
## 基本の書き方
```JavaScript
if (条件1) {
  // 条件1が真のときの処理
} else if (条件2) {
  // 条件2が真のときの処理
} else {
  // どちらにも当てはまらないときの処理
}
```
条件は上から順番に判定されるため、範囲を絞り込むような条件を並べるときは判定の順序に注意する（最も厳しい条件を先に書くなど）。

## 比較演算子
| 演算子 | 意味 |
| --- | --- |
| `<` `<=` | 未満／以下 |
| `>` `>=` | より大きい／以上 |
| `===` | 等しい（型も含めて厳密に比較） |
| `!==` | 等しくない |

# 関数
## 関数とは
一連の処理をひとまとめにしたもの。「何かを受け取って、何かを返す」マシーンのようなイメージ。
- 同じ処理を何度も使い回したいとき
- 任意のタイミングで処理を実行させたいとき

に使う。

## 定義と呼び出し
```JavaScript
// 関数の定義
function 関数名(引数) {
  // 一連の処理
}

// 関数の呼び出し
関数名(渡す値);
```

## 引数と返り値（戻り値）
引数は関数に渡す「材料」。返り値は処理の結果として関数から返ってくる値で、`return`で指定する。引数と返り値はセットで使われることが多い。
```JavaScript
function introduce(name) {
  const message = name + "さん、こんにちは";
  return message;
}

console.log(introduce("山田"));
```

# DOM操作
## DOMとは
DOM（Document Object Model）とは、HTMLの要素をプログラムから自由に操作するための仕組み。JSでHTMLの要素を取得し、操作することを「DOM操作」と呼ぶ。

## 要素の取得
`querySelector`を使うと、CSSセレクタと同じ書き方で該当する要素（最初の1つ）を取得できる。
```JavaScript
const box = document.querySelector(".sample_box");
console.log(box);
```
📎 [JavaScriptで要素を取得しよう](https://zero-plus.io/media/l_javascript/get-element/)

## イベントとクラス操作
`addEventListener`でクリックなどのイベントを検知し、`classList`メソッドでクラスの付け外しを行うのが基本の流れ。
```JavaScript
const box = document.querySelector(".sample_box");

box.addEventListener("click", function () {
  box.classList.toggle("is-active");
});
```

| メソッド | 動き |
| --- | --- |
| `classList.add()` | クラスを追加する |
| `classList.remove()` | クラスを削除する |
| `classList.toggle()` | クラスを付け外しする（ついていれば外す、なければ付ける） |

見た目の変化はCSS側（`.is-active`がついたときのスタイル）にあらかじめ定義しておき、`transition`を組み合わせるとアニメーションになる。

# 【+α】繰り返し処理
授業内では扱わなかったが、同じ処理を繰り返すための構文としてfor文・while文・forEach文がある。余裕があれば予習・復習課題のチャレンジ問題で触れておくとよい。
- **for文**：繰り返す回数があらかじめ決まっている処理向き
- **while文**：条件を満たす間だけ繰り返したい処理向き
- **forEach文**：配列の要素を1つずつ取り出して処理したいときに使う

# 本日のまとめ
1. JavaScriptはCSSだけでは実現できない、ユーザーの動きに応じた「動的」な処理を可能にする
2. 変数は`let`（再代入可）・`const`（再代入不可）を使い分ける。`var`は基本的に使わない
3. `if〜else if`で条件分岐を作るときは、条件の判定順序に注意する
