# ScrollTriggerとは
GSAPのプラグインの1つで、「スクロールして特定の位置に来たら」アニメーションを発火させることができる。
- 📎 [スクロールトリガーが使われている実際のサイト](https://cwt.jp/category/427/1)

## 導入
GSAP → ScrollTriggerの順で、headタグ内に読み込む（使用するHTMLファイルごとに確認する）。
```HTML
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.11.3/gsap.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.11.3/ScrollTrigger.min.js"></script>
<script src="js/main.js" defer></script>
```
- ScrollTriggerはGSAPの機能を使うため、必ずGSAPより後に読み込む
- 📎 [GSAPの導入方法](https://zero-plus.io/media/l_javascript/gsap/#GSAPの導入方法)／[GSAP Pluginsの導入](https://zero-plus.io/media/l_javascript/gsap-scrolltrigger/#GSAP_Pluginsの導入)

# 演習1：スクロールで順番に表示する（problemセクション）
## 仕様
- 各パネル（`.js_problem`）をスクロールで順番に表示させる
- 1秒かけて、200px下から、見えない状態から表示させる
- 緩急の付け方は`Power4.inOut`
- セクションタイトルの上辺が画面の中央に来たときに発火（目印は`.js_problem-trigger`）

```JavaScript
gsap.from(".js_problem", {
  y: 200,
  autoAlpha: 0,
  duration: 1,
  ease: "Power4.inOut",
  scrollTrigger: {
    trigger: ".js_problem-trigger", // 目印の要素
    start: "top center",            // 目印の上端が画面の中央に来たら開始
    // markers: true,               // 発火位置を画面にマーカー表示する（確認用）
  },
  stagger: {
    each: 0.6,     // 0.6秒ずつずらして次の要素を動かす
    from: "start", // 最初の要素から順番に動かす
  },
});
```
- `scrollTrigger`の中に、どこで発火させるかを書く
    - `trigger`：発火の目印にする要素
    - `start: "top center"`：2つの値が「要素のどこ」が「画面のどこ」に来たら、という指定（ここでは「要素の上端が画面の中央」）
    - `markers: true`：発火位置・終了位置を画面に表示できる。位置調整のときに便利
- `ease`：動きの緩急（加速・減速）をつける。📎 [Easingの種類（GSAP公式）](https://gsap.com/resources/getting-started/Easing/)
- `stagger`：同じクラスの要素が複数あるとき、時間差をつけて順番に動かす
    - `each`：1つずつずらす秒数
    - `amount`：全体でかける秒数（`each`と`amount`はどちらか一方を指定する）
- 📎 [Staggerを使う](https://zero-plus.io/media/l_javascript/gsap-scrolltrigger/#Staggerを使う)

## 【発展】GSAPを使わずに同じ動きをつける（Intersection Observer）
```JavaScript
const problemTrigger = document.querySelector(".js_problem-trigger");
const problems = document.querySelectorAll(".js_problem");

const observer = new IntersectionObserver(
  (entries) => {
    entries.forEach((entry) => {
      // 目印が画面に入ったら
      if (entry.isIntersecting) {
        problems.forEach((problem, index) => {
          // 0.6秒ずつずらしてクラスを追加
          setTimeout(() => {
            problem.classList.add("is-active");
          }, index * 600);
        });
        observer.unobserve(problemTrigger); // 一度動いたら監視をやめる
      }
    });
  },
  {
    threshold: 0.5, // 目印が50%見えたら
  }
);

observer.observe(problemTrigger);
```
```CSS
.js_problem {
  opacity: 0;
  visibility: hidden;
  transform: translateY(200px);
  transition: 1s ease;
}

.js_problem.is-active {
  opacity: 1;
  visibility: visible;
  transform: translateY(0);
}
```
- `IntersectionObserver`：要素が画面に入ったかどうかを監視できる、JavaScript標準の仕組み
- `setTimeout(処理, ミリ秒)`：指定した時間が経ってから処理を実行する。`index * 600`で、要素ごとに0.6秒ずつ遅らせている
- 📎 [[Intersection Observer]「スクロールして特定の位置をすぎたらふわっと表示」を簡単に実装する方法](https://tedate.jp/coding/about-intersection-observer)

# 演習2：連続アニメーション（infoセクション）
## 仕様
- 各セクションをそれぞれアニメーションさせる
- 1つ目（奇数番目）は左から、2つ目（偶数番目）は右から
- 見えない状態から表示させる。緩急は`Power4.inOut`
- 各セクションの上辺が画面中央に来たときに発火
- アニメーションさせる要素は`.js_h-slide`

```JavaScript
const items = document.querySelectorAll(".js_h-slide");

items.forEach((item, idx) => {
  gsap.from(item, {
    // インデックス番号に+1して2で割った余りが0（偶数番目）なら右から、そうでなければ左から
    x: (idx + 1) % 2 == 0 ? "100%" : "-100%",
    autoAlpha: 0,
    ease: "Power4.inOut",
    duration: 1,
    scrollTrigger: {
      trigger: item.parentNode, // itemの親要素をトリガーにする
      start: "top center",
    },
  });
});
```
- 1つずつ別のタイミングで発火させたいので、`forEach`で要素ごとに`gsap.from()`を設定している（`stagger`は1つの目印でまとめて動かすとき）
- `forEach((値, インデックス番号) => {})`：インデックス番号は0から始まるので、「何番目か」にするには`+1`する
- 📎 [forEach（ループ処理）](https://zero-plus.io/media/l_javascript/loop/)／[参考サイト（for・forEachでScrollTrigger）](https://hakoirioyaji.com/blog/gsap-scrolltrigger/#forの場合)

## 三項演算子（if文を1行で書く）
```JavaScript
// 条件 ? 条件がtrueのときの値 : 条件がfalseのときの値
x: (idx + 1) % 2 == 0 ? "100%" : "-100%"
```
上と同じことをif文で書くと次のようになる。
```JavaScript
x: function () {
  if ((idx + 1) % 2 == 0) {
    return "100%";
  } else {
    return "-100%";
  }
},
```
- 📎 [条件（三項）演算子（MDN）](https://developer.mozilla.org/ja/docs/Web/JavaScript/Reference/Operators/Conditional_Operator)

## 親要素を動的に取得する
- `item.parentNode`：その要素の**すぐ上の親要素**を取得する
- `item.closest(".js_h-slide_trigger")`：その要素から上にさかのぼって、**指定したセレクタに一致する最初の祖先要素**を取得する。HTMLの階層が変わっても目印のクラスで探せるので壊れにくい
- 📎 [parentNode（MDN）](https://developer.mozilla.org/ja/docs/Web/API/Node/parentNode)／[parentNodeの使い方（Qiita）](https://qiita.com/kasagata/items/ccb860f38e375918be5c)

# 本日のまとめ
1. ScrollTriggerはGSAPの後に読み込み、`scrollTrigger: { trigger, start }`で発火位置を指定する
2. `start: "top center"`は「要素のどこ」が「画面のどこ」に来たら、という指定
3. `stagger`を使うと、複数の要素を時間差で順番に表示できる
4. 要素ごとに別々に発火させたいときは、`forEach`で1つずつアニメーションを設定する
5. 三項演算子でif文を1行で書け、`parentNode`／`closest()`で親要素を動的に取得できる
