# 投稿の基本
## 管理画面から記事を投稿する
1. `functions.php`に、投稿でアイキャッチ画像を使えるようにするコードを書く
2. 管理画面の「投稿」から記事を作る（タイトル・本文・アイキャッチ）

## カテゴリーを作る
1. 「投稿」→「カテゴリー」で、カテゴリー名とスラッグ（URLに使う英字）を登録する（例：マーケティング＝`mark`、SEO＝`seo`）
2. 投稿一覧で各記事の「クイック編集」からカテゴリーを当てる
- 最初から「Uncategorized」にチェックが入っているので外す
- 📎 [WordPressのカテゴリーを作成して表示しよう](https://zero-plus.io/media/l_wordpress/category/)

# メインループ
取得した投稿データを、投稿の数だけ繰り返して表示する仕組み。メインループを書くと、デフォルトの「投稿」の記事一覧が表示される。

```php
<?php
if (have_posts()) :      // 投稿があれば処理に入る
  while (have_posts()) : // 投稿の数だけ繰り返す
    the_post();          // 今回の投稿の情報をセットする
?>

  <!-- ループさせる投稿の型（記事1つ分のHTML） -->

<?php
  endwhile;
else :
?>

  <!-- 投稿がないときに表示するもの -->

<?php endif; ?>
```

| 関数 | 動き |
| --- | --- |
| `have_posts()` | 投稿があるか確認する（ある間は`true`） |
| `the_post()` | 繰り返すたびに、その回の投稿データをセットし直す（1回目は1つ目の記事…） |

書き方のイメージ
1. 元のHTMLに、基本の型をはめ込む
2. 記事ごとに変わる部分（リンク・アイキャッチ・日付・タイトル）をテンプレートタグに置き換える

## ループの中で使うテンプレートタグ
| タグ | 出力するもの |
| --- | --- |
| `the_permalink()` | 投稿のURL（`a`の`href`に使う） |
| `the_post_thumbnail()` | アイキャッチ画像（`img`タグごと出力。引数で`class`をつけられる） |
| `the_time('Y.m.d')` | 公開日（`Y`＝年、`m`＝月、`d`＝日） |
| `the_title()` | タイトル |
| `the_content()` | 本文 |

```php
<article class="m_post">
  <!-- 記事のリンク -->
  <a href="<?php the_permalink(); ?>" class="m_post_link">
    <div class="m_post_thumb-wrapper">
      <!-- アイキャッチ画像（classを指定して出力） -->
      <?php the_post_thumbnail(null, array('class' => 'm_post_thumb')); ?>
    </div>
    <!-- 投稿日 -->
    <time class="m_post_date"><?php the_time('Y.m.d'); ?></time>
    <!-- タイトル -->
    <h2 class="m_post_title"><?php the_title(); ?></h2>
  </a>
</article>
```
- テンプレートタグを入れると、表示内容が投稿に合わせて変わる（動的になる）
- 📎 [メインループを使って投稿を表示しよう](https://zero-plus.io/media/l_wordpress/main-loop/)／[ブログサイトをWordPress化しよう メインループ編](https://zero-plus.io/media/l_wordpress/html-to-wordpress-mainloop/)

# ページネーション
プラグインでも作れるが、表示速度や保守性のため、コードで書けるものはなるべくコードで書く。
```php
<?php the_posts_pagination(); ?>
<!-- 出力：前へ 1 2 3 4 5 次へ -->

<?php
the_posts_pagination(array(
  'prev_text' => '',              // 「前へ」の文字（空にして擬似要素で「＜」を作ることもできる）
  'next_text' => '',              // 「次へ」の文字
  'screen_reader_text' => ' ',    // 読み上げソフト向けの説明文（今回は読み上げないよう空白に）
));
?>
```
- クラス名はWordPressが自動で出力するので、検証ツールで確認してスタイルを当てる
- 1ページに表示する件数は、管理画面の「設定」→「表示設定」→「1ページに表示する最大投稿数」で変える（初期値は10件）
- 📎 [プラグインなしでページャーを実装する方法](https://webcreatetips.com/coding/3439/)／[固定ページに投稿一覧とページネーションを設置する](https://shogo-log.com/setup-pagenation/)

# カテゴリーの表示
## 各記事のカテゴリーを表示する
```php
<?php
if (have_posts()) :
  while (have_posts()) :
    the_post();
    $cat = get_the_category();   // 今の投稿のカテゴリー情報（配列）を取得
    $cat_name = $cat[0]->name;   // 1つ目のカテゴリー名だけ取り出す
?>
  <span class="m_post_meta-cat"><?php echo esc_html($cat_name); ?></span>
```
- `$`は、PHPで「これは変数です」という印
- `$cat[0]`は配列の1つ目。カテゴリーが複数ついていても、1つだけ表示している

## カテゴリー一覧を表示する（ヘッダー）
```php
<?php
$cats = get_categories();                          // 登録されている全カテゴリーを取得
foreach ($cats as $cat) :                          // 1つずつ取り出して繰り返す
  $cat_link = get_category_link($cat->term_id);    // カテゴリーページのURLを取得
?>
  <li class="l_header-nav_item">
    <a href="<?php echo esc_url($cat_link); ?>" class="l_header-nav_link"><?php echo $cat->cat_name; ?></a>
  </li>
<?php endforeach; ?>
```

| 書き方 | 取得するもの |
| --- | --- |
| `$category->term_id` | カテゴリーID |
| `$category->slug` | スラッグ |
| `$category->name` | カテゴリー名 |

- 中身が分からないときは`echo`で画面に出して確認するとよい
- カテゴリーの情報を取得して、動的に表示できる

# サイドバー
## カテゴリーごとの記事数を表示する
- `category.php`の`<aside>`〜`</aside>`を`sidebar.php`に移し、カテゴリー一覧のループで「リンク・カテゴリー名・記事数」を動的にする

## サブループで新着記事を表示する
メインループとは別の投稿を表示したいときに使う。

```php
<?php
$args = array(
  'post_type' => 'post',      // 投稿タイプ
  'posts_per_page' => 4,      // 表示する記事数
);
$the_query = new WP_Query($args);   // サブループのお決まりのコード

if ($the_query->have_posts()) :
  while ($the_query->have_posts()) : $the_query->the_post();
?>
  <!-- 繰り返すHTML -->
<?php endwhile; ?>
<?php wp_reset_postdata(); // サブループで取得した情報をリセットする ?>
<?php endif; ?>
```
- `wp_reset_postdata()`で、メインループの情報に戻しておく
- 📎 [メインループとサブループの違い](https://wordpress-web.and-ha.com/difference-between-main-loop-and-subraop/)
