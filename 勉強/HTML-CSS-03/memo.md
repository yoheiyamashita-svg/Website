# スニペット登録
- VSCode左下の歯車アイコンを選択
- 「ユーザースニペットの構成」をクリック
- 検索バーが上に出てくるので、「css」で検索
- 検索結果にある「css.json」（もしくは単に「css」と書かれている）をクリック
- もともとあるコードを消して、下記のコードを貼り付ける

- prefix：呼び出すときに打ち込む文字列

- body：呼び出したい文字列、プロパティたち

- description：スニペットの説明。なくてもよい！


- ▽ $1ってなに？？
    - $1→カーソルの初期位置
    - $2,$3...　　tabキーを押すとカーソルが移動

- ▽ tabキーってどれ？
    - windows： tab
    - mac ：→|

【widthとmax-widthの違い】
width: 要素の幅を、指定した値（ピクセル、パーセントなど）に固定
max-width: 要素の幅が指定した値を超えないように制限する

可変にしつつ上限を設けたい場合、例としてwidth: 100%;と max-width: 960px;の組み合わせて使ったりします。
こうすることによって、PCでは最大960pxで表示され、スマホでは画面幅に合わせて縮小させることができますね！
→ レスポンシブ表示でよく使います！
簡単に言うと、max-widthはこれ以上大きくならないでね〜という指定ができるプロパティです！
画面が小さい時にはそれに追従して縮めてくれるので、とっても便利！！

小林佳奈
17:53
「💡+a | ポイント」
box-sizingがborder-boxの場合

box-sizing:border-box;が設定されていると、paddingもwidthに含まれるので、
デザイン幅を840pxと指定すると、実際にはパディング分が含まれてコンテンツ部分は少し小さくなります(約808px)。
そのため、画面上でデザイン通りの大きさを表示するために、左右のパディング分を足してmax-widthを872pxに設定しています。

「⚠️注意点」
box-sizing:content-boxの場合はpaddingはwidthに含まれません。
この場合は、paddingを足して指定すると、デザインより幅が広くなってしまいます。
案件や実務の際は、reset.cssに何が書かれているか必ず確認しましょう。

ZeroPlusの教材では、box-sizingをborder-boxで統一しているので、基本的にpaddingの値もwidthに含めて計算します👨‍🏫
