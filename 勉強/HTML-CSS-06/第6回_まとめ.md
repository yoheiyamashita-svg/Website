# 画像を指定サイズでトリミングする（object-fit）
画像の比率を変えずに、指定した幅・高さの枠にきれいに収めたいときに使う。
```CSS
.sample_img {
  height: 350px;
  object-fit: cover;
}
```
- `object-fit: cover;`をつけると、指定した高さ・幅の枠に画像の比率を保ったままトリミングして収められる（はみ出す部分は見えなくなる）
- `img`タグに直接高さを指定しただけでは画像が縦横比を保たず歪んでしまうため、`object-fit`と組み合わせるのが定番
- `object-fit`は`img`タグに書く

| 値 | 動き |
| --- | --- |
| `cover` | 縦横比を保ったまま、枠を完全に覆うようにリサイズ（はみ出た部分は切れる） |
| `contain` | 縦横比を保ったまま、枠に収まるようにリサイズ（余白ができることがある） |

- 📎 [CSSだけで画像をトリミングできるobject-fit](https://www.webcreatorbox.com/blog/object-fit)

# 疑似要素でラベル装飾をつける
見出し上の小さいラベルのような装飾は、`::before`疑似要素で`content`を出し分けて作ることができる。
```CSS
.sample-title {
  position: relative;
}

.sample-title::before {
  display: block;
  color: var(--accent-color);
  font-size: 16px;
  font-weight: normal;
  letter-spacing: 0.3em;
}

.sample-title__company::before {
  content: "COMPANY";
}

.sample-title__blog::before {
  content: "BLOG";
}
```
- 同じベースクラス（`.sample-title`）に、モディファイアクラス（`__company`／`__blog`）を組み合わせて`content`の中身だけを切り替えている（[[第2回]]の複数クラスの考え方と同じ）

# マーカーのような下線をlinear-gradientで作る
`linear-gradient()`の色の切り替わり位置を調整すると、テキストの下側だけに色がついた「マーカーで引いたような下線」を再現できる。
```CSS
.sample_emphasis {
  background: linear-gradient(
    transparent 0%,
    transparent 75%,
    var(--accent-color) 75%,
    var(--accent-color) 100%
  );
}
```
- 0%〜75%までを透明（`transparent`）、75%〜100%だけを色付きにすることで、テキストの下25%だけに色の帯が入り、マーカーのように見える
- パーセントの数値を変えると、下線の太さ（どこから色がつくか）を調整できる
- 上から見て「△%〜□%が何色」という考え方で指定する
- `0%`と`100%`は省略できる（`linear-gradient(transparent 70%, #43cfe8 70%)`でも同じ）
- カンマを忘れるとそれだけで表示されないことがあるので注意

# 横スクロールを実装する
ボタンなどの一覧が画面幅に収まらず、横にスクロールさせたいときのパターン。
```CSS
.sample_wrapper {
  width: 100%;
  overflow-x: scroll;
}

.sample_list {
  width: calc(343px * 4 + 32px * 3);
  display: flex;
  flex-wrap: wrap;
  gap: 16px 32px;
}
```
- 親要素に`overflow-x: scroll;`をかけ、中の`ul`などの幅を`calc()`で「アイテム幅×個数＋余白×個数」分だけ明示的に広くとることで、横スクロールが実現する
- `flex-wrap: wrap;`をかけると、`flex`の子要素が幅に収まらないときに自動で折り返される（[[第1回]]の表示形式参照）
- 📎 [【CSS】overflowの使い方解説！要素のはみ出し解決](https://zero-plus.io/media/overflow/)

# 疑似要素でバツ印（開閉アイコン）を作る
クリックして開閉するアコーディオンなどのアイコンは、`::before`で縦棒・`::after`で横棒を同じ位置に重ねて作ることができる。
```CSS
.sample_mark {
  width: 20px;
  height: 20px;
  position: relative;
  flex-shrink: 0;
}

.sample_mark::before {
  content: "";
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  width: 2px;
  height: 100%;
  background: var(--black-color);
}

.sample_mark::after {
  content: "";
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  width: 100%;
  height: 2px;
  background: var(--black-color);
}
```
- 開閉マーク（バツ印）は、`::before`で縦棒・`::after`で横棒を同じ位置（`top: 50%; left: 50%;` + `translate(-50%, -50%)`）に重ねて作る（[[第5回]]の上下左右中央寄せと同じ考え方）
- `flex-shrink: 0;`をつけると、`flex`の他の要素が広がってもこのアイコンの大きさは縮まない（[[第3回]]参照）
- `:not(:first-child)`のように「最初の要素以外」を指定できる疑似クラスもある（2個目以降にだけ余白をつけたい時などに便利、[[第1回]]参照）
- `::before`と`::after`の使い分け
    - `position`をつけない場合：中身の前に出るか後に出るかが変わるので、使い分けが必要
    - `position: absolute;`をつける場合：要素が浮いて`relative`を基準に配置されるので、どちらでもよい
- 片方の軸だけ中央寄せする書き方（スニペット登録しておくと便利）
```CSS
/* 左右だけ中央寄せ（X軸） */
position: absolute;
left: 50%;
transform: translateX(-50%);

/* 上下だけ中央寄せ（Y軸） */
position: absolute;
top: 50%;
transform: translateY(-50%);
```

※ KV（ファーストビュー）への色付きフィルター・上下左右中央寄せのテクニックは[[第5回]]で扱った内容と同じなので、そちらを参照。

# 下層ページのKVをモジュールにする（m_kv）
サービスページなどの下層ページのKVは、他のページでも使い回すことを想定して`m_`のモジュールとして作る。似たスタイルの箇所（トップページのKV）からコードを真似できないか、まず探すのがポイント。
```CSS
.m_kv {
  height: 320px;
  background: linear-gradient(rgba(51, 51, 51, 0.2), rgba(51, 51, 51, 0.2)),
    url(../img/bg_kv.jpg) center 22% / cover;
  position: relative;
}

.m_kv-box {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  text-align: center;
  width: 100%;
}
```
- `background-position`の`center 22%`は「横は中央、縦は上から22%の位置」を基準に画像を表示する指定。キーワード（`top`など）だけでなく、%で細かく位置を調整できる
