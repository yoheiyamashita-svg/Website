# CTAと共通パーツの使い回し
**CTA（Call To Action）**：Webサイトの訪問者を具体的な行動（お問い合わせ・資料請求など）に誘導するためのパーツ。今回はお問い合わせフォームにつなげることが目的のサイトなので、お問い合わせに誘導している。
- ヘッダー・KV・CTA・フッターは各ページで共通なので、`service.html`からそのままコピーして`company.html`に移して使い回す（[[第2回]]の下層ページの考え方と同じ）
- コンテンツ幅を指定するときは、パソコンサイズのことも考えておくとよい
- 使い回せるパーツは使い回す。どこを変えなければいけないかは、デザインデータを見て探す

## l_contentsとl_containerの使い方
| クラス | 役割 |
| --- | --- |
| `l_contents` | セクションの上下の余白 |
| `l_container` | コンテンツ幅（最大幅）。左右16pxの余白もつく |

- `l_contents`と`l_container`は**別の要素**に書く（同じ要素に書くと打ち消し合う）。どちらを外側にしてもよい
- `l_container`は3種類あるので、セクションごとに決める
    1. そのセクションのPC幅のデザインを確認する
    2. `-sm`・無印・`-lg`のどれに当たるか、変数に入っている値と見比べる

| 変数 | PCサイズの横幅 |
| --- | --- |
| `--content-width-sm` | 800px |
| `--content-width` | 960px |
| `--content-width-lg` | 1088px |

- Figmaの赤いガイドラインの幅や、スタイルガイドに登録されている横幅で確認できる
- 変数を忘れたら[[第4回]]を振り返る

# 見出しがつく大きな区切りを作る（section）
見出しがつく大きな区切りは`section`タグで作る。会社概要ページでは、同じクラス名で2つのセクション（代表メッセージ／ミッション・ビジョン）を作り、2番目だけ背景色を変えている。
- 📎 [sectionタグ](https://zero-plus.io/media/l_html_css/learn-basic-tag/#sectionタグ)

## 見出しの左に縦ラインの装飾をつける
```CSS
.sample_section_title {
  padding-left: 24px;
  position: relative;
}

.sample_section_title::before {
  content: "";
  position: absolute;
  left: 0;
  top: 50%;
  transform: translateY(-50%);
  width: 8px;
  height: 32px;
  background: var(--primary-color);
}
```
- `padding-left`で装飾のぶんの余白を空けておき、疑似要素を左端に`absolute`で置く。縦方向は`top: 50%; transform: translateY(-50%);`で中央に揃える（[[第5回]]参照）
    - `position`を使うと要素が浮くので、`padding-left`は擬似要素の幅も含めた値にする
- 青い「線」に見えるが、`border`ではなく縦長の長方形を作るイメージ。装飾・デザイン的な意味のものは擬似要素で作ることが多い
- 擬似要素の復習
    - 必須の記述は「`::before`か`::after`」と「`content: "";`」の2つ
    - 擬似要素はデフォルトでインライン要素なので、幅と高さが効かない。`display: block;`などに変える必要がある
    - `position: absolute;`をつけると、インラインブロックのように幅と高さが効くようになる（📎 [position:absoluteをつけた時の性質まとめ](https://nishinatoshiharu.com/absolute-element-characteristics/)）
- 📎 [positionとtransformで中央寄せ（復習用）](https://kakechimaru.com/pos_center_transform/)／[relative・absolute・fixedの違い](https://saruwakakun.com/html-css/basic/relative-absolute-fixed)
- 📎 [CSSの擬似要素で擬似的に要素を追加しよう](https://zero-plus.io/media/l_html_css/pseudo-element/)

# nth-of-typeとnth-childの使い分け
同じようなセクションが並ぶページで、偶数番目（または奇数番目）だけ背景色を変えたいときなどに使う。
```CSS
.sample_section:nth-of-type(2n) {
  background: var(--gray-color02);
}
```
- `nth-of-type`：同じ種類のタグ（ここでは`section`）の中で何番目かを数える
- `nth-child`：兄弟要素の中で（タグの種類を問わず）何番目かを数える
- 違う種類のタグが混在している場所では結果が変わることがあるので、使い分けに注意する
- 📎 [CSSのnth-childとnth-of-typeの使い方と違いを解説](https://zero-plus.io/media/css-child-type/)

## 【+α】:nth-child() の of S 構文
- `:nth-child(2 of p)`と書くと、「`p`の中で2番目」という意味になる（`p:nth-of-type(2)`と同じ）
- 従来の`p:nth-child(2)`は「兄弟要素の2番目が`p`なら適用」という少しややこしいルールだが、`of`を使うと何を数えているか直感的に分かる
- 主要ブラウザで使えるようになったのは2023年春ごろ。古い環境に対応するときは注意
- 📎 [:nth-child() の “of S” 構文](https://media.wwg.co.jp/blog/t62600)

# 画像の拡張子の選び方
画像を書き出すときは、色数や用途に応じて拡張子を使い分ける。

| 形式 | 特徴 | 用途 |
| --- | --- | --- |
| jpg | たくさんの色を軽量で表現するのが得意。ただし透過はできない | フルカラーの写真 |
| png | 透過ができる。色数が多いとファイルサイズが大きくなる | 透過のある写真、カラーの少ない画像 |
| svg | 拡大しても画像が荒くならない特殊な形式。色数が多いと重くなる | ロゴ、アイコン |

# tableタグで表を作る
会社情報のような縦に項目が並ぶ表は、`table`・`tr`・`th`・`td`の4つのタグで構成する。
```HTML
<table class="sample_table">
  <tr class="sample_tr">
    <th class="sample_th">項目名</th>
    <td class="sample_td">内容</td>
  </tr>
</table>
```
```CSS
.sample_tr:nth-child(2n) {
  background: var(--gray-color02);
}
```
| タグ | 由来 | 意味 |
| --- | --- | --- |
| `table` | ― | 表全体 |
| `tr` | table row | 行 |
| `th` | table head | 見出しセル |
| `td` | table data | データセル |

- `tr`には`padding`が効かないので、`th`・`td`に`padding`を指定する（📎 [trタグに効かないスタイル](https://naruweb.com/coding/tr_css/)）
- 表の項目の高さは`height`ではなく`padding`で調整する。項目の内容が変わったときにスタイルが崩れるのを防げる
- セルの枠線を1本にまとめるときは、`table`に`border-collapse: collapse;`をつける
```CSS
.table {
  border-collapse: collapse; /* 隣り合うセルの枠線を重ねて1本にする */
}

.table_head,
.table_data {
  border: 1px solid #e6e6e6;
  padding: 16px 0;
}
```
- アクセシビリティを意識した表には、他にもいろいろなタグがある（📎 [アクセシビリティを意識したtableの作り方](https://qiita.com/degudegu2510/items/e69994d1ab976d57f015)）
- `nth-child`で偶数番目を指定する書き方は`even`または`2n`、奇数番目は`odd`または`2n+1`
    - 覚え方：odd（3文字）→ 奇数、even（4文字）→ 偶数
- 表のHTMLは、ジェネレーターで作ってコピペすると楽（セル結合もできる。📎 [テーブルタグジェネレーター](https://tabletag.net/ja/)）
    - タグやCSSを生成するものをジェネレーターという。「〇〇 ジェネレーター」で探せる
    - スニペット登録するときは、テキストを残しても消してもよい。自分が分かりやすい形で登録する
- 📎 [【tableタグの使い方】表を作成するときの注意点とポイントの解説](https://zero-plus.io/media/l_html_css/table-style/)
- 📎 [偶数番目だけ指定を変える（疑似クラス）](https://zero-plus.io/media/l_html_css/using-css-pseudo-classes/)

## 見出しセルの右に短いラインの装飾をつける
```CSS
.sample_th {
  width: 132px;
  padding: 16px 0 16px 8px;
  position: relative;
}

.sample_th::before {
  content: "";
  position: absolute;
  right: 0;
  top: 50%;
  transform: translateY(-50%);
  height: 2px;
  width: 40px;
  background: var(--primary-color);
}
```
- `th`に`width`を指定して見出し列の幅を固定し、右端に疑似要素で短い横線を引いている
- 線の太さは`height`で決めている（見出しの縦ラインと同じ考え方）
    - `height: 0;`＋`border: 2px solid`で作っても、デザイン通りならOK。ただし値が大きくなるとずれる可能性がある。`border`は「枠線」だと知っておく
- デザインデータのグループ化は、コーディングの構造のヒントになる（今回は線が見出しとグループになっていたので、`th`を基準にした）

# dlタグで縦並びの表を作る
お問い合わせフォームのように「見出し→入力欄」が縦に繰り返される構造は、`table`タグ以外に`dl`タグ（`dt`＝見出し、`dd`＝内容）でも表現できる。
```HTML
<dl class="sample_form_list">
  <dt class="sample_form_heading">項目名</dt>
  <dd class="sample_form_detail">
    <input type="text" class="sample_form_input" />
  </dd>
</dl>
```
- `dl`タグの方が、縦並びの見出し＋内容という構造を簡潔に書けることが多い
- `dl`は定義リスト（説明リスト）。辞書のようなイメージ。よくある質問やお問い合わせフォームで使われることが多い
- `form`タグはフォーム全体を囲うように**1つだけ**書く。`action=""`はWordPressで自動的に入るので気にしなくてよい
- `dl`タグは`dt`・`dd`を囲うように**1つだけ**書く
- 📎 [説明リストタグ（dl・dt・dd）の使い方](https://webliker.info/html/13381/)／[dl・dt・ddの意味と使い方](https://webst8.com/blog/html-dldtdd/)

| タグ | 由来 | 辞書でいうと |
| --- | --- | --- |
| `dl` | description list | 辞書そのもの |
| `dt` | description term | 単語 |
| `dd` | description details | 単語の説明 |
- 📎 [デザインデータからコーディング！お問い合わせフォームを作ってみよう](https://zero-plus.io/media/l_html_css/coding-practice-contact/)

## よく使うinputタグのtype属性
| type属性 | 用途 |
| --- | --- |
| `text` | 通常の文字入力（会社名、氏名など） |
| `tel` | 電話番号の入力 |
| `email` | メールアドレスの入力 |
| `radio` | 複数の選択肢から1つだけ選ぶ |

- `type`属性は入力欄に合わせて変える
    - `tel`：スマホなどで、最初から数字入力のキーボードを表示してくれる
    - `email`：`@`がないとエラーを出してくれる。過去に入力したメールアドレスも候補に出る
- `radio`を使う場合は、同じ`name`属性の値をグループ内で揃える（どれか1つしか選べないようにするため）
    - `name`の値は、共通していれば何でもよい。誰が見ても分かりやすいものにする
- `label`タグを`input`と`for`／`id`で紐づけておくと、ラベル文字をクリックしても入力・選択ができるようになり、ユーザーが操作しやすくなる
    - 「ボタンが小さくて押しづらい」というストレスを減らせる＝ユーザビリティの向上

| 部品 | 選べる数 |
| --- | --- |
| チェックボックス（`type="checkbox"`） | 複数選択できる |
| ラジオボタン（`type="radio"`） | 1つだけ選択できる |

- 入力欄に合った`type`を選ぶのは、ユーザーの入力ストレスを減らして離脱を防ぐ工夫
- チェックボックスは`type="checkbox"`。ラジオボタンと同じく`label`の`for`と`input`の`id`を一致させると、文字をクリックしても選択できる
- `value`属性はWordPressで自動的に入るので気にしなくてよい

### labelとinputの組み方
次の2パターンのどちらでもよい。
```HTML
<!-- パターン1：labelでinputを囲う -->
<li>
  <label for="request-01">
    <input type="radio" name="request" id="request-01" />
    <span>Web制作</span>
  </label>
</li>

<!-- パターン2：labelとinputを兄弟要素にする -->
<li>
  <input type="radio" name="request" id="request-01" />
  <label for="request-01">Web制作</label>
</li>
```
- `input`に`required`をつけると、入力必須にできる
- `label`に`cursor: pointer;`をつけると、クリックできることが伝わりやすい

### ラジオボタンを作る3ステップ
1. `input`タグの`type`属性を`"radio"`にする（これだけで丸いボタンになる）
2. `label`タグの`for`属性と`input`タグの`id`属性を、項目ごとに同じ値にする（テキストを押しても選択できる）
3. すべてのラジオボタンの`name`属性を同じにする（1つだけ選べる）

```HTML
<ul class="sample_form_radio-list">
  <li class="sample_form_radio-item">
    <!-- idとlabelのforを同じ値にする。nameは全項目で同じにする -->
    <input type="radio" name="category" value="a" id="item-a" class="sample_form_radio" />
    <label for="item-a" class="sample_form_label">項目A</label>
  </li>
  <!-- 項目の数だけliを複製する -->
</ul>
```

## フォームの装飾のポイント
```CSS
/* 「必須」ラベルを見出しの右端に配置する */
.sample_form_heading {
  position: relative;
}

.sample_form_required {
  position: absolute;
  right: 0;
  top: 50%;
  transform: translateY(-50%);
}

/* reset.cssで消えたラジオボタンの見た目を戻す */
.sample_form_radio {
  appearance: radio;
}

/* テキストエリアのサイズをユーザーが変えられないようにする */
.sample_form_textarea {
  width: 100%;
  height: 250px;
  resize: none;
}
```
- 入力欄は`width: 100%;`で横幅いっぱいにし、`border`・`border-radius`・`padding`で見た目を整える
- `appearance`：ブラウザ標準のフォーム部品の見た目を制御するプロパティ。リセットCSSで`appearance: none;`にされていると、ラジオボタンの丸が表示されなくなるため、`radio`で戻している
    - reset.cssの`appearance: none;`は、デフォルトの表示を消して自由に装飾するための記述
    - 装飾まで作らないときは、`appearance: auto;`でデフォルトの状態に戻す
    - 【+α】ラジオボタンは擬似要素でカスタマイズできる（📎 [ラジオボタンのカスタマイズ](https://itokoba.com/archives/768)／[チェックボックス・ラジオボタンをCSSで装飾する](https://kiomiru.co.jp/blog/coding/radio-checkbox/)）
- 📎 [実はたくさんあるinputのtype属性](https://zenn.dev/ma_me/articles/ee2af9f7e9f4ad)／[今どきの入力フォームの書き方](https://ics.media/entry/11221/)（卒業後）
- `resize: none;`：`textarea`の右下にあるサイズ変更ハンドルを無効にする
- 送信ボタンは[[第5回]]の`m_btn`に、色だけ変えるModifier（`m_btn__contact`）を追加して使い回している
