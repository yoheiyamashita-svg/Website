## 解説
- 画像を書き出すときは、色数に応じて拡張子を使い分ける

| 形式 | 特徴 | 用途 |
| --- | --- | --- |
| jpg | たくさんの色を軽量で表現するのが得意。ただし透過はできない | フルカラーの写真 |
| png | 透過ができる。色数が多いとファイルサイズが大きくなる | 透過のある写真、カラーの少ない画像 |
| svg | 拡大しても画像が荒くならない特殊な形式。色数が多いと重くなる | ロゴ、アイコン |

- `nth-of-type(2n)`：同じ種類のタグ（ここでは`section`）の中で偶数番目にだけスタイルを当てられる
- `nth-of-type`と`nth-child`の違い：`nth-of-type`は「同じタグの中で何番目か」、`nth-child`は「兄弟要素の中で（タグの種類を問わず）何番目か」で数える点が異なる

## 解説
- 表を作る基本タグは`table`・`tr`・`th`・`td`の4つ（`table`＝表全体、`tr`＝行、`th`＝見出しセル、`td`＝データセル）
- `nth-child`で偶数番目を指定する書き方は`even`または`2n`、奇数番目は`odd`または`2n+1`

## 解説
- **`dl`タグで表を作る**：表の作り方には`table`タグ以外に`dl`タグ（`dt`＝見出し、`dd`＝内容）もある。特に縦並びの表現では`dl`タグの方が簡潔に書けることが多い
- **`label`タグ**：`input`と`for`／`id`で紐づけておくと、ラベル文字をクリックしても入力・選択ができるようになり、ユーザーが操作しやすくなる
- `input`タグは`type`属性（`text`／`tel`／`email`／`radio`など）によって入力の種類を使い分ける
