# position
positionプロパティは、要素の「位置」を指定する際に使用する。特に以下の場面で用いられる
- 要素を自由に配置したい
- 要素の重なり順を変えたい
- ヘッダーを固定して表示したい

## 指定できる値
- static(初期値)：
    - 位置を動かすことはできない
- relative
    - 位置の基準としたい要素に指定することが多い。
    - absoluteとセットで使用
    - 距離指定のプロパティを設定すれば、位置調整が可能
    - z-indexで重なり順を指定する事が可能
- absolute
    - 親要素を基準に絶対的な位置を決める
    - 親要素をrelative(またはfixed)にすることで、親要素を基準に、距離指定のプロパティで設定した位置に表示されます。
    - 元々の配置されていた場所からはその要素の高さが無くなる（一段上に浮く）
relativeとセットで使用する
自分の親要素を基準とし、要素の移動が可能
z-indexで重なり順を指定する事が可能
fixed
画面の決まった位置に要素を固定します。webサイトをスクロールしても、要素が固定されるので、追従した状態で表示されます。

指定方法・特徴はabsoluteとほぼ同じと考えてOKです。

基準がwindow全体になるので、注意が必要です。画面左上からどれだけの距離に配置されるかを考えて位置を指定しましょう。

sticky
stickyは、日本語訳で粘着という意味があります。

その名の通り、スクロールした際に要素をシールのように粘着させ、固定表示することができます。

使用する際は、親要素と子要素を準備し、子要素に対してstickyを記述します。

このとき、親要素をsticky containerと呼び、子要素はsticky itemと呼びます。

親要素を用意することで、追従する範囲を指定することができます。

特徴

親要素を用意することで固定する範囲を指定できる
追従が開始されるとfixedのように要素が固定され、指定した位置（`top`など）に留まり続ける
親要素の表示範囲を超えると、追従が解除されて通常の配置（static）に戻る

弱点として、`sticky`はブラウザによって挙動が異なる・使えないケースがあるので、[can I use](https://caniuse.com/?search=sticky)で対応状況を確認しておくとよい。

## 実践例①：本文＋サイドバー（sticky container / sticky item）
```HTML
<div class="sticky_wrapper">
  <div class="sticky_container">
    <main class="sticky_main">
      <!-- 記事本文など、縦に長いコンテンツ -->
    </main>

    <aside class="sticky_aside">
      <!-- スクロールに追従させたい要素（広告・目次など） -->
    </aside>
  </div>
</div>
```
```CSS
.sticky_aside {
  position: sticky;
  top: 48px; /* 画面上端から48pxの位置で止まる */
}
```
- `.sticky_container`：sticky containerにあたる。子要素の追従できる範囲＝この要素の高さ分になる
- `.sticky_aside`：sticky itemにあたる。`.sticky_main`（記事本文）より要素の高さが低いため、スクロールしても途中まで画面に留まり続け、`.sticky_container`の下端に到達すると追従が終了する

## 実践例②：ヘッダーの固定
ヘッダーをスクロールしても画面上部で固定表示させたい、というのも典型的な`sticky`の使いどころ。
```CSS
.header {
  position: sticky;
  top: 0;
  left: 0;
  z-index: 100;
}
```
- ポイント：`sticky`は親要素の中でのみ固定される。`top`プロパティをつけ忘れると機能しない
- `z-index`を指定しておくことで、他の要素の下に隠れず常に前面に表示される
- `sticky`を使うことで、要素が浮いてスタイルが崩れるのを防ぐことができる（`fixed`だと元の位置から要素が抜けてレイアウトが崩れやすい）

## positionまとめ表
|値|基準|重なり順(z-index)|主な用途|
|----|----|----|----|
|static|なし（初期値）|指定不可|通常の配置|
|relative|自分自身の元の位置|指定可能|absoluteの基準を作る|
|absolute|position指定のある直近の親要素|指定可能|要素を自由な位置に配置する|
|fixed|ブラウザの画面（viewport）|指定可能|要素を常に同じ位置に固定したい時（ただし元の位置から浮くのでレイアウト崩れに注意）|
|sticky|親要素（sticky container）の範囲内|指定可能|スクロールに合わせて一定範囲だけ追従させたい要素（ヘッダー固定など）|

# 疑似要素（::before / ::after）
HTML側に要素を追加することなく、CSSだけである要素の「直前」「直後」に新しい要素があるかのようにコンテンツを追加できる仕組み。

## 書式
```CSS
セレクタ::before {
  content: "追加したい内容"; /* contentプロパティは必須。装飾だけの場合は空文字でOK */
  /* その他のプロパティ */
}

セレクタ::after {
  content: "追加したい内容";
}
```
- `::before`：対象要素の中身の「一番最初」に生成される
- `::after`：対象要素の中身の「一番最後」に生成される
- `content`プロパティを指定しないと、疑似要素は生成されない（画面に表示されない）
- 生成された疑似要素は、通常の要素と同じようにCSS（`position`、`width`、`color`など）で装飾できる

# transform / transition
## transform
要素の見た目（移動・回転・拡大縮小・傾斜）を変形させるCSSプロパティ。要素そのものの配置（`position`など）は変えず、見た目上だけを変形させる。

|関数|効果|記述例|
|----|----|----|
|`translate(x, y)`|移動させる|`transform: translate(30px, 50px);`|
|`rotate(角度)`|回転させる|`transform: rotate(45deg);`|
|`scale(倍率)`|拡大・縮小させる|`transform: scale(1.2);`|
|`skewX(角度)` / `skewY(角度)`|傾斜させる|`transform: skewX(15deg);`|

## transition
プロパティの値が変化する際に、変化の過程をアニメーションのように滑らかにするCSSプロパティ。`:hover`などの状態変化と組み合わせてよく使う。
```CSS
transition: プロパティ名 タイミング関数 時間;
```
- `transition`は「これから変化するかもしれないプロパティ」を持つ要素（変化前の状態）に指定する
- `:hover`時の見た目（変化後の状態）に`transform`を指定することで、ホバーした瞬間に指定した時間をかけて滑らかに変形する

# 演習-1：ページネーション
ブログサイトの記事一覧では、1ページに表示される記事の数に制限を設けている。制限を超えた記事がある場合、他のページへ移動するために使うのがページネーション。

## HTMLの構造
```HTML
<div class="pagination">
  <span class="pagination_numbers pagination_numbers__current">1</span>
  <a href="" class="pagination_numbers">2</a>
  <span class="pagination_numbers pagination_numbers__between">…</span>
  <a href="" class="pagination_numbers">10</a>
  <a href="" class="pagination_numbers pagination_numbers__next"></a>
</div>
<!-- /.pagination -->
```

## 模範コード
```CSS
.pagination {
  display: flex;
  align-items: center;
  justify-content: center;
  margin-top: 56px;
  gap: 8px;
}

.pagination_numbers {
  font-weight: bold;
  width: 40px;
  height: 40px;
  display: flex;
  align-items: center;
  justify-content: center;
  border: 2px solid #f7f7f7;
  background: #fff;
}

.pagination_numbers__current {
  color: #fff;
  border-color: #008db7;
  background: #008db7;
}

.pagination_numbers__between {
  font-size: 14px;
  border: none;
}

.pagination_numbers__next {
  position: relative;
}

.pagination_numbers__next::before {
  /* contentは擬似要素に必須！ */
  content: "";
  width: 8px;
  height: 8px;
  border-top: 1px solid #333;
  border-right: 1px solid #333;
  position: absolute;
  top: 50%;
  left: 32%;
  transform: translateY(-50%) rotate(45deg);
}
```

## 解説：複数クラスを使う
共通部分が多い中、一部だけ異なるスタイルがある場合は、次のように役割分担をする。
- 共通部分をまとめるクラス → `.pagination_numbers`で枠線や背景色などベースの見た目をまとめている
- 部分的に異なる部分をまとめるクラス → `.pagination_numbers__current`（現在のページ）、`.pagination_numbers__next`（次へボタンの矢印）のように、差分だけを追加のクラスで表現する

「次へ」ボタンの矢印は、疑似要素（`::before`）とボーダー、`transform`の組み合わせで作られている。

# 演習-2：カテゴリーページの作成（下層ページ①）
ブログサイトにおける「分類ごとの記事一覧」のページを**カテゴリーページ**と呼ぶ。使用するファイルは`category.html`が一般的。

## 下層ページをつくる上でのポイント
- 共通部分（ヘッダー・フッターなど）はコピー&ペーストで使い回す
- 他ページへのリンクは、`href`属性内に相対パスで記述する

## 模範コード
`index.html`の中身と比較して、変更・追記は以下のみ。
```HTML
<h1 class="category-title">
  「マーケティング」<br />の記事一覧
</h1>
```
```CSS
.category-title {
  font-size: 24px;
  font-weight: bold;
  text-align: center;
}
```

# 演習-3：個別ページの作成（下層ページ②）
ブログサイトにおける「記事の本体」のページを**個別ページ**と呼ぶ。使用するファイルは`single.html`が一般的。今まで習った内容の応用のため、`index.html`を参考にしながら作成する。

## 模範コード
```HTML
<main class="main">
  <article class="single">
    <div class="single_thumb-wrapper">
      <img src="img/thumb_single.jpg" alt="SEO" class="single_thumb" />
    </div>
    <!-- /.single_thumb-wrapper -->
    <div class="single-meta">
      <time class="single-meta_date">2021.06.05</time>
      <a href="category.html" class="single-meta_cat">SEO</a>
    </div>
    <!-- /.single-meta -->
    <div class="single_content">
      <h1>記事タイトル</h1>
      <p>本文...</p>
    </div>
    <!-- /.single_content -->
  </article>
</main>
```
```CSS
.single {
  width: 100%;
  padding: 0 16px;
}

.single-meta {
  display: flex;
  justify-content: space-between;
  align-items: center;
  margin-top: 24px;
}

.single_content {
  margin-top: 24px;
}

.single_content h1 {
  font-size: 22px;
  font-weight: bold;
}

.single_content p {
  margin-top: 40px;
  line-height: 2;
}
```

## 解説
- クラス名の付け方：ページ固有の要素にはページ名（`single`）を接頭辞にする
- CSSの指定の仕方：`.single_content h1`のように、子孫セレクタでまとめて指定する方法もある（WordPress化した際、記事本文中の見出しには直接クラス名をつけられないことが多いため、この書き方に慣れておくと実務でも役立つ）

# よく使うCSSプロパティ
- `color`：テキストの文字色を指定
    - キーワードによる指定：「black」「white」「red」「blue」など、色名を直接指定する
        - 例：`color: red;`
    - 16進数（HEX）による指定：`#` に続けて16進数で指定する
        - 例：`color: #ff0000;`
    - RGB / RGBA値による指定：赤・緑・青の数値や透明度で指定する
        - 例：`color: rgb(255, 0, 0);`
        - 例：`color: rgba(255, 0, 0, 0.5);`
- `font-size`：テキストの大きさを指定
    - px（ピクセル）による指定：固定サイズで指定する
        - 例：`font-size: 16px;`
    - rem / em（相対値）による指定：ルートや親要素のサイズを基準とした割合で指定する
        - 例：`font-size: 1.5rem;`
    - %（パーセント）による指定：親要素の文字サイズに対する割合で指定する
        - 例：`font-size: 100%;`
