# レスポンシブに必要な材料3つ🥕
## ① ビューポート
レスポンシブを導入するためにHTML側に必要なもの（基本はテンプレートに書いてある）。
```HTML
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

## ② メディアクエリ
画面幅が違うサイズになったときのスタイルを書くエリア。
```CSS
@media screen and (min-width: 〇〇px) { 
  .class {
    color: #fff;
  }
}
```
❗️もともと書いていたCSSの必ず**下**に書く❗️

## ③ ブレイクポイント
レスポンシブのスタイルを適用させたい画面幅の数値。＜目安＞
- タブレット(Tab)：768px
- パソコン(PC)：1080px

# レスポンシブの作業の流れ
レスポンシブをする際は、以下の流れで作業を進めていく。
1. **デザインデータを見比べる**
2. **変更箇所を見つける**
3. **CSSでメディアクエリとスタイルを記述する**

上記の繰り返しが基本。スマホ・PCの間のサイズは、時にデザインデータにない仕様を汲み取ってコーディングを行う必要がある。

## デザインデータを確認する際の主な変更箇所
- 横並びの箇所を縦並びにする（またはその逆）
- テキストの大きさ／改行を調節する
- 要素の横幅／高さを調節する
- 要素の表示／非表示を切り替える
- 余白の大きさを調節する

## 教材のレスポンシブ仕様（今回の例）
- スマホ版のスタイル：cssファイルに記述済み（モバイルファーストで書かれているので書き換え不要）
- タブレット版のスタイル：画面幅が768px〜1080px未満の間に適用
    ```CSS
    @media screen and (min-width: 768px) {
    }
    ```
- パソコン版のスタイル：画面幅が1080pxより大きい際に適用
    ```CSS
    @media screen and (min-width: 1080px) {
    }
    ```

# レスポンシブでよく使うテクニック
## 横並び⇄縦並びの切り替え
画面幅によって「横並びにしたい要素」が変わることはよくある。
- `display: flex;`は、横並びにしたい要素の直前の親要素にかける
- メディアクエリを書く場所は、ベースのスタイルのすぐ下（「ベースのスタイル→768px→1080px」の順で書くとうまく反映される）
```CSS
.sample {
  display: block;
}

@media screen and (min-width: 1080px) {
  .sample {
    display: flex;
    align-items: center;
    justify-content: space-between;
  }
}
```

## 画像がつぶれないようにする
横並びにした画像とテキストを`flex`で並べたとき、画面幅が狭まると画像側の横幅まで縮んでしまうことがある。画像側に`flex-shrink: 0;`をつけておくと、`flex`で横並びにしたときに画像の横幅が縮まらないようにできる。

## 中央寄せ
要素の左右の`margin`を`auto`にすると、その要素を中央寄せにできる。
```CSS
.sample {
  max-width: 872px;
  margin-right: auto;
  margin-left: auto;
}
```

## ホバーアニメーション
PCサイズ時のリンクなどにホバーした時の変化をわかりやすくする工夫。`transition`を使うと状態の変化を滑らかにできる（[[第2回]]参照）。
```CSS
.sample_link {
  padding-top: 4px;
  border-bottom: 4px solid transparent;
  transition: border-bottom-color 0.24s;
}

.sample_link:hover {
  border-bottom-color: #fff;
}
```

## 特定の画面幅だけ改行を制御する
`br`タグで改行を操作している場合、`br`タグに`display: none;`をかけることで、その画面幅では改行しないようにできる。レスポンシブ時に、特定の要素を非表示にする方法としても使える。
```CSS
@media screen and (min-width: 768px) {
  .sample_break {
    display: none;
  }
}
```

## 差分だけを上書きする
レスポンシブ対応は、変化している箇所のみをメディアクエリ内に書けばよい。スタイル全体を書き直す必要はなく、最大幅（`max-width`）や文字サイズなど、その画面幅で変わる部分だけを追加・上書きする。

# headタグ内を考える
head内には、サイトごとに書き換えが必要な情報（ファビコン・Webクリップアイコン・OGPなど）をまとめて記述する。

## ファビコン・Webクリップアイコン
- **ファビコン**：ブラウザのタブに表示される小さいアイコン
- **Webクリップアイコン**：スマートフォンでサイトをホーム画面に追加した時に表示されるアイコン

## OGP（Open Graph Protocol）
SNSなどでURLがシェアされた時に表示される、タイトル・説明文・画像などを指定する仕組み。

## 模範コード
```HTML
<!-- favicon/web-clip-icon -->
<link rel="icon" href="favicon.ico" />
<link rel="icon" href="favicon.svg" type="image/svg+xml" />
<link rel="apple-touch-icon" href="webclip.png" />

<!-- ogp -->
<meta property="og:site_name" content="ZeroPlus Blog" />
<meta property="og:url" content="URL" />
<meta property="og:type" content="article" />
<meta property="og:title" content="ZeroPlus Blog" />
<meta property="og:description" content="サイトの説明文" />
<meta property="og:image" content="シェア時に表示する画像のURL" />
<meta property="og:locale" content="ja_JP" />
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:description" content="サイトの説明文" />
<meta name="twitter:image:src" content="シェア時に表示する画像のURL" />
```
これを`<meta name="format-detection" content="telephone=no" />`と`<!-- google fonts -->`の間に入れる。

## 解説
- metaタグ内に必要な情報を書くと、より（SEOやSNSシェアの観点で）強いサイトになる
- head内の記述は覚える必要はなく、都度コピペして値だけ書き換えればよい

# 今日の授業のポイント
1. レスポンシブに必要な材料は3つ：ビューポート／メディアクエリ／ブレイクポイント
2. レスポンシブの作業の流れ：デザインと見比べる→違いを見つける→CSSで書いていく
3. メディアクエリを書く場所は、もともとのCSSのすぐ下！
4. `margin`の左右の値を`auto`にすると中央寄せができる
5. `flex`の子要素が潰れた場合は、潰れてほしくない要素に`flex-shrink: 0;`をつける
6. `display: flex;`は横並びにしたい要素の直前の親要素に当てる
