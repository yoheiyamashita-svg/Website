# 演習-1：会社概要とブログ（トップページの続き）
## 仕様
- 基本的にはデザインの通り
- 書いてあるHTMLをもとにCSSを記述する
- 復習ポイント：各CSSの記述・装飾をつくる・値の計算

## ヒント
- 文字の色など、わかりやすいところから始める
- 装飾は疑似要素で作る
- 画像の比率を変えずに、指定したサイズにおさめる

## 模範コード
```CSS
/* ---------- .top_info ---------- */
.top_info:nth-child(2n) {
  background: var(--gray-color02);
}

.top_info_img {
  height: 350px;
  object-fit: cover;
}

.top_info_block {
  position: relative;
  margin-top: 24px;
}

.top_info_block::before {
  content: "";
  position: absolute;
  right: 0;
  top: 50%;
  transform: translateY(-50%);
  height: 2px;
  width: calc(100% - 140px);
  background: var(--primary-color);
}

.top_info_title {
  font-size: 24px;
  font-weight: bold;
}

.top_info_title::before {
  display: block;
  color: var(--accent-color);
  font-size: 16px;
  font-weight: normal;
  letter-spacing: 0.3em;
}

.top_info_title__company::before {
  content: "COMPANY";
}

.top_info_title__blog::before {
  content: "BLOG";
}

.top_info_txt {
  margin-top: 64px;
}

.top_info_btn-wrapper {
  margin: 64px auto 0;
  max-width: 343px;
  height: 64px;
}
```

## 解説
- `calc()`関数を使うと要素のサイズを計算式で指定できる → 画面幅などが変わっても柔軟にサイズが変化する（例：`width: calc(100% - 140px);`）
- `object-fit: cover;`をつけると、指定した高さ・幅の枠に画像の比率を保ったままトリミングして収められる
- 見出し上の小さいラベル（COMPANY／BLOG）のような装飾は、`::before`疑似要素で`content`を出し分けて作る（同じ`.top_info_title`をベースに、`__company`／`__blog`のモディファイアクラスで内容を切り替える）

# 演習-2：サービスページKV
## 仕様
- 基本的にはデザインの通り
- 他ページで使い回すことを想定する
- テキストは中央寄せ

## ヒント
- 背景画像にフィルターをかける（半透明のレイヤーを重ねる）
- 文字とボタンは上下中央配置にする
- 似たスタイルの箇所からコードを真似できないか探してみる

## 模範コード
```HTML
<div class="m_kv">
  <div class="m_kv-inner l_container-lg">
    <div class="m_kv-box">
      <h1 class="m_kv-title">サービス</h1>
      <p class="m_kv-desc">
        弊社が提供するマーケティング<br class="u_lg-dn" />サービスを紹介します。
      </p>
    </div>
    <!-- /.m_kv-box -->
  </div>
  <!-- /.m_kv-inner -->
</div>
<!-- /.m_kv -->
```
```CSS
.m_kv {
  height: 320px;
  background: linear-gradient(rgba(51, 51, 51, 0.2), rgba(51, 51, 51, 0.2)),
    url(../img/bg_kv.jpg) center 22% / cover;
  position: relative;
}

.m_kv-box {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  text-align: center;
  width: 100%;
}

.m_kv-title {
  font-size: 24px;
  font-weight: bold;
  color: var(--white-color);
  text-shadow: 2px 2px 2px rgba(170, 170, 170, 0.16);
}

.m_kv-desc {
  font-weight: bold;
  color: var(--white-color);
  margin-top: 16px;
}
```

## 解説
- `linear-gradient()`は2色のグラデーションだけでなく、同じ色を2つ重ねることで「半透明のフィルター」としても使える（`background`に、色レイヤーと画像を`,`で並べて重ねる）
- 上下左右中央配置の定番パターン：`position: absolute;` + `top: 50%; left: 50%;` + `transform: translate(-50%, -50%);`
- 同じような構造・見た目の箇所は、既存のコードを真似て応用すると早い

# 演習-3：サービスページメニュー
## 仕様
- 基本的にはデザインの通り
- 書いてあるHTMLをもとにCSSを記述する
- ボタンは溢れていて、横にスクロールが可能

## ヒント（手順を分解する）
1. ボタンの大きさをpxで指定する
2. ボタンを横並びにする
3. ボタンを2行にする（折り返し）
4. ボタンが横に4つ並ぶ横幅を`ul`に指定する
5. 余白を設定する
6. 横スクロールをできるようにする

## 模範コード
```CSS
.service_menu_message {
  font-size: 18px;
  font-weight: bold;
  text-align: center;
}

.service_menu_message__emphasis {
  font-size: 24px;
  background: linear-gradient(
    transparent 0%,
    transparent 75%,
    var(--accent-color) 75%,
    var(--accent-color) 100%
  );
}

.service_menu_desc {
  font-size: 12px;
  margin-top: 40px;
  text-align: center;
}

.service_menu_txt {
  font-size: 12px;
  margin-top: 16px;
  text-align: center;
}

.service_menu_wrapper {
  margin-top: 40px;
  width: 100%;
  overflow-x: scroll;
}

.service_menu_list {
  width: calc(343px * 4 + 32px * 3);
  display: flex;
  flex-wrap: wrap;
  gap: 16px 32px;
}

.service_menu_item {
  width: 343px;
  height: 64px;
}

.service_menu-scroll {
  margin-top: 40px;
}

.service_menu-scroll_txt {
  font-size: 12px;
  font-weight: bold;
  color: var(--gray-color);
  text-align: center;
}

.service_menu-scroll_arrow {
  width: 40px;
  height: 40px;
  display: flex;
  justify-content: center;
  align-items: center;
  border-radius: 50%;
  margin: 8px auto 0;
  border: 2px solid var(--gray-color);
  color: var(--gray-color);
}
```

## 解説
- マーカーのような下線は、`linear-gradient()`の色の切り替わり位置（`0% / 75% / 100%`など）を調整して、テキストの下側だけに色をつけることで再現できる
- 横スクロールは、親要素に`overflow-x: scroll;`をかけ、中の`ul`（`.service_menu_list`）の幅を`calc()`で「ボタン幅×個数＋余白×個数」分だけ明示的に広くとることで実現する
- `flex-wrap: wrap;`をかけると、`flex`の子要素が幅に収まらないときに自動で折り返される

## ④ Q&Aを作ろう
### 仕様
- 基本的にはデザインの通り
- 「開いている状態」のものを作成する（クリックして開く想定）
- 一つだけ作成して、残りは複製でよい

### ヒント
- HTMLの構造をもとに、`flex`を使って並べる
- アイコン（Q／Aのマーク、開閉のバツ印）は疑似要素で作る

### 模範コード
```CSS
.service_faq {
  background: var(--gray-color02);
}

.service_faq_wrapper {
  padding-top: 80px;
}

.service_faq_button {
  background: var(--white-color);
  width: 100%;
  box-shadow: 2px 2px 2px rgba(170, 170, 170, 0.16);
  padding: 32px 16px;
  display: flex;
  justify-content: space-between;
  align-items: center;
}

.service_faq_button:not(:first-child) {
  margin-top: 16px;
}

.service_faq_content {
  display: flex;
}

.service_faq_content__a {
  margin-top: 40px;
}

.service_faq_icon {
  font-size: 14px;
  font-weight: bold;
  padding-right: 16px;
}

.service_faq_icon__q {
  color: var(--primary-color);
}

.service_faq_icon__a {
  color: var(--accent-color);
}

.service_faq_txt {
  font-size: 14px;
  font-weight: bold;
  text-align: left;
  margin-right: 16px;
}

.service_faq_mark {
  width: 20px;
  height: 20px;
  position: relative;
  flex-shrink: 0;
}

.service_faq_mark::before {
  content: "";
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  width: 2px;
  height: 100%;
  background: var(--black-color);
}

.service_faq_mark::after {
  content: "";
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  width: 100%;
  height: 2px;
  background: var(--black-color);
}
```

### 解説
- 開閉マーク（バツ印）は、`::before`で縦棒・`::after`で横棒を同じ位置（`top: 50%; left: 50%;` + `translate(-50%, -50%)`）に重ねて作る
- `flex-shrink: 0;`をつけると、`flex`の他の要素が広がってもこのアイコンの大きさは縮まない
- `:not(:first-child)`のように「最初の要素以外」を指定できる疑似クラスもある（2個目以降にだけ余白をつけたい時などに便利）

# 本日のまとめ
1. 疑似要素の使い方を思い出せた
2. `object-fit: cover;`で画像のトリミングができる
3. マーカーのような下線は`linear-gradient`で作れる
4. `overflow`プロパティははみ出した要素に影響を与えられる（`overflow-x: scroll;`で横スクロール）
5. `flex`の子要素の折り返しは`flex-wrap`を使う
